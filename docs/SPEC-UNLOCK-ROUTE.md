- 經驗：`huntExp(regionLv(rk, star), true) × rewardRatio`；草原 ★1～★5 每場 **23／32／41／47／56**。主線 1-1、1-2 各 +30。升級 `hrNeed(hr) = 20 + 15(hr−1)`，累計：Lv2 **20**、Lv3 **55**、Lv4 **105**、Lv5 **170**、Lv6 **250**、Lv7 345、Lv8 455、Lv10 720、Lv12 1045、Lv15 1645。
- 每場秒數：`tools/nw-sim/sim.mjs`＋`v2Rules({flow:'none'})`＋`attendDodge 0.11／attendDef 0.73`，學生用 `realPersonas()`（`data-public/typehero-speed-20261120.json`，284 人 bestWpm）：慢 P25＝7 字/分、中 P50＝11、快 P90＝25.7，另加極慢 4。草原 ★1 平均 **209／139／61 秒**（極慢 260），★1～★3 勝率都 100%。
- 時間模型：開場 5 分鐘（取名、選武器、教學大樓三堂課）；每場外加 60 秒（委託板、結算、走路）；每節新世界 15 分鐘，剩下時間不夠打一場就等下一節；一天最多開 2 個新星級（`starsPerDay`）；每次挑能開的最高星。悲觀版：開場 7 分、每場外加 90 秒（括號內）。

## B. 補經驗任務（等級不夠時任務自己變成「打倒 N 隻」）

**原則**：解鎖任務的完成條件永遠是「等級到了（或老師解開）」；畫面上的「打倒 N 隻」只是告訴孩子要做什麼，打什麼都算經驗，所以**一定解得開、不用刷同一隻**。

1. **缺口**：`D = expTotal(L) − expTotal(nw)`，`expTotal(nw) = Σ_{l<nw.hr} hrNeed(l) + nw.hrExp`，`expTotal(L)` 同式到 L。`D ≤ 0` → 任務當場完成。
2. **打哪裡**（依序找第一個符合的，這叫「補經驗目標」）：
   ① **借下一個主線任務的目標**：解鎖任務後面第一個有 `target`、沒 `hold` 的任務，它的星級現在打得到（`starOpen` 而且沒 `newStarLocked`）就用它（例：1-1u 時借 1-2 的咕咕鳥 ★1）。這樣補經驗＝往主線前進，不是額外刷怪。
   ② 否則：**最新開放區域裡、自己打贏過的最高星**（`zone[rk]`，0 就用 ★1），不指定魔物（這一星任何一隻都算）。挑「打贏過的」＝勝率高、不會越打越挫折。
3. **數量**：`e = huntExp(regionLv(rk, star), true)`（不算活動加倍，寧可多算），`n = min(3, ceil(D / e))`，最少 1。
   - 上限 3：一次最多叫他打 3 隻，看起來不會很遠；打完 3 隻還不夠，就照新的 D 重算（極少見：只有連輸才會）。
   - 只會變少：`D` 只減不增，換到更高星 `e` 變大，所以數字不會往上跳。輸／逃走拿到一部分經驗，數字可能不變，不會變多。
   - 打更高星、別的魔物也算（經驗多就少打幾隻），文字要說出來。
4. **文字**（國小白話；`L` 等級、`B` 建築名、`X` 魔物或「草原 ★N 的魔物」）：
   - 標題 `tOf(nw)`：`再打倒 ${n} 隻${X}，${B}就開張！`
   - 說明 `hint`：`${B}要獵人等級 ${L}。到委託板找有 📌 的單子；打更高星的經驗更多，打幾隻就會少幾隻。`
   - 進度 `prog(nw)`：`經驗 ${expTotal(nw) − expTotal(L−1)}／${hrNeed(L−1)}`（就是升到 L 那一級的經驗條）。
   - 等級已經夠、只差段沒開：不出現（`hold`），不要寫「施工中」以外的任何話。
5. **委託板連動（`nw-board-rot.js` 的 `goalCards`）**：解鎖任務是「有目標的主線」，走跟 1-4 一樣的路：
   - `const t = mq.targetOf ? mq.targetOf(nw) : mq.target`，後面所有 `mq.target`／`MAIN_QUESTS.find(...).target` 都改用這個 `t`。
   - `goal0` 用 `best(list)` 挑那一星的魔物（打得贏、板上已有的優先、避開剛打的那隻），`match` 只配那一星（不要配 ≥，否則 🔥 挑戰單也會變成刷新不掉的目標單）。
   - 活動指定同一區同一星：照現有規則合成一張（`t.mk` 沒有 → 用活動的魔物）。
   - 標籤：①借來的目標寫「📌 任務目標」；②寫「📌 往任務前進」（沿用 `qs-goal` 樣式）。
   - 刷新（SPEC-SHOP-BOARD2 B1）照舊不換目標單；打贏後「主線不卡住」那條（B1 第 6 點）一樣適用。
6. `goalOf(nw)`（村莊黃色箭頭）也改用 `targetOf`，`building` 給 `'board'`；任務完成、慶祝完後箭頭換到剛開的建築（見 D）。
