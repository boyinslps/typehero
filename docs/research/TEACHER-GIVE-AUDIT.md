# 學生能拿到的東西，老師給得出去嗎？（盤點）

2026-11-19。老師要求：**學生能拿到的東西，基本上都能從老師管理頁給出去**（一律寄信，學生到信箱領）。
這份是逐項盤點（對照 `nw-data.js` 的 `defaultNw()`、`newworld.js` 的 `applyReward()`），以及這次怎麼補。

寄信給東西的流程沒有變：教師頁寫 `mg_mail/{ID}` → 學生端領取時才寫進自己的存檔（`NW.mail[信件ID]` 記已領）。
**教師頁不直接改學生存檔**：兩台電腦同時玩、學生離線時，直接改存檔會被蓋掉或蓋掉別人。

## 二、這次新增的禮物種類

`word`、`weapon`、`coins`、`potion`、`exp`、`item`、`mat` 原本就有。新增：

| type | 欄位 | 學生領到時 | 重複領／已經有 |
|---|---|---|---|
| `bp` | `key`＝圖紙 id（`bp_` 開頭，資料表裡要有） | 通知「圖紙「○○」」＋提示鐵匠鋪開張就能用 | 已經會了：通知寫「已經會了」，不重複加 |
| `hr` | `n`＝2～50 的整數（升到幾級） | 通知「獵人等級升到 ○」；星星跟著加 | 已經比這高：通知寫「已經比這個高了」，等級不動 |
| `zone` | `key`＝區域（沒 `wip` 的）、`n`＝1～5 | 通知「○○ ★n 以下都算過關」；★5 且有下一區就多寫「○○也開放了」 | 已經走得更遠：不往下改，通知寫「走得比這裡更遠了」 |
| `dex` | `key`＝魔物 id | 通知「魔物圖鑑：○○」 | 本來就打過：不動次數 |
| `tut` | `key`＝`dodge`／`defend`／`attack` | 通知「教學大樓：○○課」 | 已學會：不重複 |

另外 `word` 的通知改成「新的稱號詞條：○○」，並寫出原本的解鎖條件、提示「到背包點名字下面的稱號，就能把它戴上」；這封信順便讓別的條件跟著達成的詞條一起解鎖（`checkWords`）。

**每一種都遵守同一套規矩**（`newworld.js` 的 `REWARD` 表，`itemKnown`／`applyReward`／`itemLabel` 都從這張表來）：
1. 領之前先檢查整封信的每個東西這個版本都認得、欄位合理（key 在資料表裡、數量是範圍內的整數）；有一個不認得，**整封不領**，信上寫「請按 F5 重新整理再來領」，不標已領。
2. 領取成功只加一次：信件固定 ID＋`NW.mail`（領前會重讀雲端存檔合併，雙分頁不會領兩次）。
3. 未知 type（舊版學生遇到新種類）整封不領，不報錯。
4. 狀態類（`hr`／`zone`／`dex`／`tut`）領完立刻重新檢查主線任務、詞條與測試員任務，獎勵與通知照常跳出，學生不用等下一場。
5. 資料表查詢一律用 `hasOwnProperty`（`key: 'constructor'` 之類的字不會被當成存在）。

## 三、刻意不做的（與原因）

1. **直接改勝敗、戰績、場次、各武器勝場**：會讓稱號、活動排行榜、進步獎的比較基準失真。要補成就就頒詞條。
2. **直接標記任務完成、直接蓋測試員章**：任務是依狀態算的，直接標記會跳過獎勵或蓋章卻沒達成。補條件（`zone`／`dex`／`tut`）就會自己完成。
3. **改學生拚好的稱號、改初心武器、改造型**：這些是學生自己做的選擇。
4. **改已領信件、序號、介紹／公告看過的紀錄**：會造成重複領。
5. **單獨改星星**：目前星星只隨 HR 增加、沒有花星星的功能，改了會跟等級對不上；用 `hr` 升級星星就會跟著給。
6. **直接改存檔**：教師頁一律寄信。學生離線或同時開兩個分頁時，直接寫存檔會被蓋掉，也沒有「學生領到」的通知。

## 四、第 2 段（裝備）要怎麼接

學生端與教師頁都是**一張表一列**，沒有散在各處的 `if`：

1. `newworld.js` 的 `REWARD` 加 `gear: { known, apply, label }`（規格 SPEC-STAGE2 §3.10：`key` 在 `GEAR_DEFS`、`c` 不高於上限、`p` 0～5；滿 60 件整封不領）。
2. `teacher/gifts.js` 的 `GIFT_TYPES` 加一列：`pick: () => Object.entries(GEAR_DEFS).map(([k, d]) => ({ value: k, label: d.name, group: 格名稱 }))`，顏色與強化值用 `qty` 或另加欄位；`itemLabel` 補一行同樣的字。
3. 如果之後有「限定造型」，同樣加一個 `look` 型別。

**以後新增下列資料，教師頁都不用改，清單自己會出現**：`WORDS`（稱號）、`GIFT_WEAPONS`（禮物武器）、`ITEM_DEFS`（道具）、魔物的 `drops`／`rare`（材料與圖紙）、`REGIONS`（區域，沒 `wip` 的）、`MONSTERS`（圖鑑）、`TUT_LESSONS`（教學課）。
`t5.test.js` 有測：動態塞一個假稱號、假道具、假材料進資料表，清單馬上多一項。

## 五、教師頁怎麼用

- **🏷 頒稱號**（學生卡、人物卡）：搜尋（稱號、解鎖條件的字都能找）→ 選一個 → 看「學生會看到的信」→「寄出稱號」。已經擁有的標「已擁有」、信已經寄出還沒領的標「已寄出，還沒領」，兩種都不能再選。信的固定 ID 是 `title_{詞條id}_{學生docId}`，來源記成「頒獎」，會留操作紀錄。
- **🎁 給東西**（人物卡、學生卡）：跳到「✉ 信箱」，收件人已經選好，游標停在「加一個禮物」。種類下拉＝所有禮物種類；稱號、材料、圖紙有搜尋；選了稱號會顯示解鎖條件，補發類（等級、區域、圖鑑、教學課）會顯示注意事項。
- **看他有什麼**：學生卡有「稱號詞條（三組）、武器、道具、材料、圖紙」，人物卡下方也有同樣一份，給之前看一眼避免重複。
- **數量防呆**：超過平常用量會再確認一次：字元 >1000、回復藥 >20、獵人經驗 >500、改名卡 >5、材料 >50、獵人等級直接升到 >15、區域打贏到 ★5。
