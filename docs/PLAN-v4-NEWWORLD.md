## 0. 一頁講完

**原本的世界一個字都不動**（全班討伐、班級排行、四階品質、三棵天賦樹照舊）。
打到夠強的孩子可以進入**新世界**，那裡的玩法用一句話講：

```
挑一隻魔物 → 打倒牠 → 撿素材 → 做出更強的武器 → 去挑更強的魔物
```

| 新東西 | 給小學生的一句話 |

### 1.1 總覽

| 項目 | 數字 |
|---|---|
| 雲端紀錄 | 326 筆（真的打過至少一場：253 人） |

### 1.2 五個要改進的方向

**① 一半的孩子只打 1～2 場就沒再回來。**
新世界是給「已經上手」的孩子更長遠的目標，但不能讓它變成另一套要從頭學的遊戲。
→ 新世界的每個系統都要**一句話講得完**、**畫面上有發亮提示告訴你下一步做什麼**。

**② 天賦系統很多孩子看不懂——39% 有點數卻一個都沒點。**
v3 之後的 113 人裡，**44 人一個天賦都沒點，其中 43 人手上點數夠點第一個**，
最多的抱著 569 點沒花；而且其中 28 人**已經看過天賦介紹**了。
推測原因：「第 n 個花 20n−10 點」這種遞增花費對小學生太抽象、點數數字看不出「我能不能點」。
→ 新世界的星圖改成**一級一顆星、一顆星點一個節點**，不用算數；
  有星星沒花時，營地的「星圖」按鈕會一直閃。（舊世界也建議補上這個閃爍提示，見 §9。）

**③ 武器嚴重偏食：法杖 58%、匕首 23%、弓箭 18%。**
弓箭樹幾乎沒人點（「蓄能上場」全校只有 1 人點）。但匕首的戰績分中位（15）其實比法杖（11.7）高。
→ 新世界用**屬性＋魔物弱點**讓孩子有理由換武器（「這隻怕水，我的水弓比較好打」）。

**④ 孩子打得很準，但慢。** 正確率中位 100%、速度中位 11 字/分。
→ 新世界的難度主要來自**內容變難**（成語、英文、詩句），不是要求更快；
  時限給得寬，讓「準但慢」的孩子也打得完。

**⑤ 選品質的眼光是對的。** 選普通的中位 9 字/分、精良 11、史詩 14、傳奇 22——
孩子會依自己能力挑難度。→ 「**自己選星等**」這個設計可以放心交給他們。

## 2. 誰可以進新世界

**建議門檻：歷史最高到達 LV12**（就是現在解鎖「傳奇」的同一條線）。

- 目前符合的有 **32 人（約 13%）**，剛好是一班 1～2 個「打到沒東西挑戰」的孩子。
- 只用一條規則，孩子好記：「傳奇解鎖的時候，新世界的門也開了。」
- 教師控制台加一個開關「新世界：依門檻／全部開放／關閉」，老師可以臨時放寬。

> 候選：LV10（55 人）或 LV8（92 人）。要更多人進來就往下調，數字在 `BALANCE.newWorld.unlockLevel`。

進出方式：營地多一扇「🌋 新世界」傳送門，兩邊隨時可以切換；
**全班討伐（老師按開始比賽）永遠在原本的世界進行**，新世界只做個人狩獵。

## 3. 狩獵委託板（取代「一場打一路小怪」）

### 3.1 一場狩獵長什麼樣

- 一場＝**一隻大魔物**，時限 **3 分鐘**（跟現在標準場一樣長）。
- 魔物有一條大血條，打字攻擊的方式跟現在完全一樣（Enter 送出、Esc 跳過、三把武器的爆發照舊）。
- **血量剩一半時魔物會「生氣」**：畫面變紅、吼一聲，之後題目長一級，但牠受到的傷害 +20%。
  這是唯一的特殊機制，孩子只要記得「牠生氣了，加油」。
- 時間內打倒＝**討伐成功**，結算掉素材；時間到沒打倒＝**撤退**，仍然拿到保底素材（見 §5.3）。

### 3.2 委託板畫面

```
┌────────── 狩獵委託板 ──────────┐
│ [泡泡蛙]   打：注音  怕：木   ★★☆☆☆  │
│ [咕咕鳥]   打：詞語  怕：火   ★☆☆☆☆  │
│ [墨鱗龍]   打：成語  怕：木   🔒先討伐咕咕鳥 │
│ [ABC機械蟹] 打：英文  怕：水   ★★★☆☆  │
└──────────────────────────────┘
選一隻 → 選星等（只能選已解鎖的）→ 出發
```

每張卡片只放四樣東西：**圖、要打什麼字、怕什麼屬性、星等**。不放數字。

### 3.3 自己選星等

| 星等 | 題目 | 魔物血量 | 掉落 |
|---|---|---|---|
| ★1 | 最簡單的那一層 | ×1.0 | 素材 ×2 |
| ★2 | | ×1.4 | 素材 ×3 |
| ★3 | 中等 | ×1.9 | 素材 ×4，稀有率↑ |
| ★4 | | ×2.5 | 素材 ×5，稀有率↑↑ |
| ★5 | 最難的那一層 | ×3.2 | 素材 ×6，必掉稀有 |

- **討伐 ★N 才解鎖同一隻的 ★N+1**（魔物獵人的升階感，規則一句話）。
- 星等同時決定題目難度與血量；血量曲線沿用 `ctkAt()` 的層級（A～D）概念，
  所以慢的孩子打 ★3 跟快的孩子打 ★3「要打幾下」差不多。數字最後用 `tools/` 的模擬器校。

**最終魔物「混沌巨龍」**：10 隻都討伐過才出現，每生氣一次就換一種題目（注音→成語→英文…），
是新世界的畢業考。

### 4.1 英文魔物要特別處理的事

- 打英文要**切換輸入法**。出發前、以及偵測到輸入框出現注音符號時，跳大字提示：
  「這隻要打英文！按 **Shift** 切換成英文喔」。
- 英文是逐字母判定，**沒有組字問題**，比中文好做。大小寫一律不分。
- 題庫對準教育部國小英語「基本 300 字」，★1 只有字母和 cat/dog 這種三字母字。
- 三年級才開始學英文：英文魔物在委託板上標「建議三年級以上」，但不鎖。

### 4.2 要新增的題庫（`assets/banks/`）

| 檔名 | 內容 | 預估題數 |
|---|---|---|
| `nw_idiom.json` | 國小常見成語（★1～3 只打成語，★4～5 打含成語的短句） | 150 |
| `nw_english.json` | 字母、國小 300 字、短句，依星等分層 | 300 |
| `nw_poem.json` | 課本與常見唐詩詩句 | 80 |
| 注音系 | 沿用現有題庫，用注音模式出題 | — |
| 詞語系、標點系 | 沿用 `common_*`、`special_staff` | — |

格式沿用現有的 `{ t, z }`；英文題沒有注音，`z` 省略。每筆加一個 `star` 欄位標星等。

## 5. 屬性、素材、工坊

### 5.1 屬性只有三個，像剪刀石頭布

```
        💧 水
       ↗     ↘
   🌿 木  ←  🔥 火

水滅火、火燒木、木吸水
```

- 打到魔物怕的屬性：**傷害 ×1.5**，傷害數字變大、跳「弱點！」。
- **沒有「被抵抗」的懲罰**，打錯屬性就是普通傷害——不讓孩子覺得選錯被罰。
- 原本的武器＝「無屬性」，在新世界照樣能用，只是吃不到弱點加成。

### 5.2 素材：每隻魔物只掉兩種

| 種類 | 範例 | 怎麼拿 |
|---|---|---|
| 一般素材 | 泡泡蛙的「泡泡黏液」 | 每場一定掉，數量看星等 |
| 稀有素材 | 泡泡蛙的「彩虹泡泡」 | 機率掉，星等越高、評價越好機率越高；★5 必掉 |

10 隻魔物＝20 種素材，加上混沌巨龍 1 種，共 21 種。背包一頁排得下，不用分頁。

### 5.3 保底（重要）

撤退（時間到沒打倒）也給 **1 個一般素材**，並依造成的傷害比例再加。
資料裡一半孩子只玩 1～2 場，「白打一場什麼都沒有」是最容易讓人不回來的時刻。

### 5.4 工坊：做武器、強化武器

**3 種武器 × 3 種屬性 ＝ 9 把屬性武器**，例如「火焰法杖」「流水弓」「森林匕首」。

```
┌─────── 火焰法杖 Lv1 ───────┐
│  需要：炎牙狼的牙  ■■■□□ 3/5    │
│        熔岩龜的殼  ■■□□□ 2/5    │
│                                │
│        [ 還差 3 個素材 ]         │   ← 湊齊時變成金色發亮的「打造！」
└────────────────────────────┘
```

| 等級 | 攻擊力 | 需要 |
|---|---|---|
| Lv1 打造 | +10% | 同屬性兩隻魔物的一般素材各 5 |
| Lv2～Lv4 強化 | 每級 +10% | 一般素材越要越多 |
| Lv5 覺醒 | +50%，並獲得一個小技能 | 要稀有素材 |

覺醒技能每把一個，一句話講得完，例如：
- 火焰法杖：「詠唱成功時，魔物燒傷 3 秒，每秒扣一點血」
- 流水弓：「神射手期間打倒魔物，爆擊條直接補滿」
- 森林匕首：「每連擊 10 次，回復 5 秒時間」

**武器的數字只顯示「攻擊力 120」這種一個數字**，不顯示公式。

## 6. 獵人等級 HR 與新排行

### 6.1 HR：一級＝一顆星

- 每場狩獵依星等給經驗（★1 最少、★5 最多），撤退也給一半。
- **HR 每升一級拿到 1 顆星星**，拿去星圖點一個節點。不用算花費，一顆星點一個。
- HR 的經驗條越後面越長，但前 5 級很快（第一場就升一級，確保第一場就摸得到星圖）。

### 6.2 排行重置、天賦保留

- 新世界有**自己的排行榜**，所有人從 0 開始。分兩個分頁：
  - **獵人等級**（努力分）：HR 高的在前。
  - **最快討伐**（技術分）：每隻魔物 ★5 的最快討伐秒數。孩子很愛「我是咕咕鳥紀錄保持人」。
- **原世界的排行、階級徽章、歷史紀錄全部不動**。
- **原世界的三棵天賦樹在新世界繼續生效**（就是「保留天賦」）。
  新世界的星圖是**另外疊上去**的第二套，兩邊不互相扣點。

## 7. 新世界星圖（參考 POE 天賦盤，國小版）

### 7.1 規則只有三條

1. 從正中間的「起點」開始。
2. **只能點亮跟已經亮著的星星連在一起的星星**（像連連看）。
3. 小星星＝一點點數值；大星星＝一個新能力；外圈的皇冠星＝很強的能力，但有一個小代價。

### 7.2 形狀

一張圓形星圖，共約 **45 顆星**，**一個畫面放得下，不用拖曳縮放**（電腦教室的滑鼠不好用）。
六個區塊交錯排列，**武器區**跟**屬性區**相鄰，讓「火焰法杖」這種組合自然往兩區中間長：

```
                    🔥 火焰區
                 ·  ·  ◆  ·  ·
      🗡 匕首區   ·      |      ·   🏹 弓箭區
        ◆ · · · ·      |      · · · · ◆
             ·   ·     |     ·   ·
               ·  ·  ( ★ )  ·  ·            ★ 起點
             ·   ·     |     ·   ·          · 小星星（數值）
        ◆ · · · ·      |      · · · · ◆     ◆ 大星星（新能力）
      🌿 森林區   ·      |      ·   💧 流水區   👑 皇冠星（外圈三顆）
                 ·  ·  ◆  ·  ·
                    🪄 法杖區
                       👑
```

| 區塊 | 小星星（範例） | 大星星（範例） |
|---|---|---|
| 🪄 法杖區 | 法杖傷害 +4% | 詠唱題錯 1 字仍算成功 |
| 🏹 弓箭區 | 正確率加成更高 | 開場爆擊條就有 50% |
| 🗡 匕首區 | 連擊加成 +1% | 打倒魔物後補一刀 |
| 🔥 火焰區 | 火屬性傷害 +5% | 打火弱點時再 +30% |
| 💧 流水區 | 水屬性傷害 +5% | 每場多 10 秒 |
| 🌿 森林區 | 木屬性傷害 +5% | 稀有素材掉落率翻倍 |

**三顆皇冠星**（各自在外圈，要走很遠才到）：

| 皇冠星 | 好處 | 代價 |
|---|---|---|
| 👑 全力一擊 | 所有傷害 +40% | 每打錯一題，時間少 3 秒 |
| 👑 慢工出細活 | 每場多 60 秒 | 傷害 −15% |
| 👑 寶物獵人 | 素材掉落 ×2 | 魔物血量 +25% |

代價都寫成孩子看得懂的「好處／壞處」兩行，而且**可以隨時免費重置星圖**，鼓勵實驗。

### 7.3 讓孩子「知道要去點」

這是資料裡最大的痛點（§1.2 ②），所以星圖要做到：

- 有沒花的星星時，營地的星圖按鈕**持續閃光＋顯示數字**（例：⭐×2）。
- 星圖打開時，**可以點的星星會一閃一閃**，點不到的是暗的，不用自己判斷連線。
- 第一次升 HR 時直接帶進星圖，畫面上一隻手指指著起點旁邊的星星：「點這裡試試看！」
- 滑過星星時用大字顯示一句話效果，不用數學符號（寫「傷害多一點點」，括號才放 +4%）。

## 8. 為了小學生做的簡化（整份規劃的底線）

| 魔物獵人／POE 原本的 | 這裡改成 |
|---|---|
| 武器 14 種、每種一套操作 | 沿用現有三把，只多「屬性」跟「等級」 |
| 屬性 5 種＋異常狀態 | 3 種，剪刀石頭布，沒有抵抗懲罰 |
| 部位破壞、捕獲、多段任務 | 只有「生氣」一個機制 |
| 每隻魔物掉 8～10 種素材 | 每隻 2 種，背包一頁 |
| 鍛造樹、派生、裝飾珠 | 一把武器一條線 Lv1→Lv5 |
| POE 天賦盤 1300 個節點、要拖曳縮放 | 45 顆星，一個畫面放得下 |

## 10. 資料怎麼存

沿用 `mg_scores` 一人一筆，**多一個 `nw` 物件**，Firestore 規則不用改（規則不看欄位名，見 [`DATA.md`](DATA.md) §2）。

```js
nw: {
  hr: 7, hrExp: 140,               // 獵人等級與經驗
  stars: ['c0','s1','s2','f1'],     // 點亮的星
  mats: { frog_c: 12, frog_r: 1 },  // 素材數量
  weapons: { staff_fire: 3 },       // 屬性武器等級
  equip: 'staff_fire',              // 目前裝備
  hunts: { frog: { best: 4, fastest5: 96 } },  // 每隻魔物最高星等、★5 最快秒數
  introDone: true
}
```

- 本機一樣存一份，離線也能玩；連線恢復時取大的合併（同現在的 `mergeHist()`）。
- **作弊風險跟現在一樣擋不住**（[`DATA.md`](DATA.md) §3），素材與 HR 被改會擴散，
  上線前要先決定接不接受。
