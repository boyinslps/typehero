## 1. 企畫總覽

### 1.1 一句話

> **原世界練打字，新世界練「怎麼打」**：挑魔物、看弱點、配裝備、打造武器、找出自己的流派。

### 1.2 兩個世界的分工

| | 原世界（現有，不動） | 新世界（本企畫） |
|---|---|---|
| 主要目標 | 打字速度與正確率 | 配裝、克制、策略 |
| 玩法 | 一路打小怪升級 | 選一隻大魔物狩獵 |
| 多人 | 全班討伐（老師開） | 組隊房間（學生自己開，最多 4 人） |
| 成長 | 三棵天賦樹 | 裝備＋強化＋星圖天賦（**舊天賦保留**） |
| 排行 | 戰績分 | **重新開始**，有防作弊審核 |
| 打的字 | 共用題庫 | 依魔物不同：注音、詞語、成語、英文、詩句、標點 |

### 1.3 誰能進

歷史最高到達 **LV12**（跟解鎖「傳奇」同一條線），目前 32 人。
教師後台可以改成「全部開放」或「關閉」。

### 1.4 新世界的難度從哪裡來

不是要求打更快，而是要**動腦**：

- 魔物會**攻擊你**，要靠防具撐住或靠打字閃避。
- 魔物有**特殊行為**（噴墨遮字、長護盾、隱身…），要帶對應的技能。
- 魔物有**弱點與抗性**，帶錯屬性傷害會打折。
- 高星魔物有**建議戰力**，裝備沒跟上就打不過，要回去鍛造、強化。

## 2. 設計原則：國小生看得懂

整份企畫的底線，每個系統都要通過這五條：

1. **一句話講得完。** 講不完就砍。
2. **畫面只顯示一個數字。** 「攻擊力 320」，不顯示公式。
3. **發亮＝可以做。** 能鍛造、能點星、能領任務獎勵時，那顆按鈕一定會閃。
4. **設施一個一個開。** 第一次進新世界只有委託板，打完第一場才開鐵匠鋪……由主線任務帶著走（§16）。
5. **不懲罰嘗試。** 強化一定成功、星圖免費重置、撤退也有保底、沒有抽獎。

| 魔物獵人／POE 原本的 | 新世界改成 |
|---|---|
| 14 種武器、每種一套操作 | 沿用三把武器，靠「武器機制」做出差異 |
| 屬性＋多種異常狀態 | 5 屬性，畫成一張圖就懂 |
| 部位破壞、捕獲、多段任務 | 每隻魔物只有 1 個特殊行為＋「生氣」 |
| 裝飾珠、護石、派生樹 | 防具自帶技能，套裝兩段效果 |
| 強化會失敗、會爆裝 | **強化一定成功** |
| POE 1300 個天賦節點 | 45 顆星，一個畫面放得下 |
| 抽卡、隨機詞條 | 沒有。素材決定品質，結果可以預期 |

### 3.1 概況

| 項目 | 數字 |
|---|---|
| 雲端紀錄 | 326 筆，實際打過的 253 人 |
| 年級 | 五年級 192、四年級 70、六年級 43、三年級 21 |

### 3.2 對應到企畫的問題清單

| # | 資料看到的 | 企畫對策 | 章節 |
|---|---|---|---|
| 1 | 一半的孩子玩 1～2 場就沒回來 | 主線任務帶路、每場都有保底、設施逐步解鎖 | §16、§9.5 |
| 2 | 113 人裡 44 人有天賦點卻一個都沒點（有人存 569 點） | 星圖「一級一顆星」、可點就發亮、任務直接要求點第一顆 | §17 |
| 3 | 武器偏食：法杖 58%、匕首 23%、弓箭 18% | 屬性克制＋魔物特殊行為，讓不同魔物適合不同武器 | §7、§8、§11 |
| 4 | 孩子打得準但慢 | 防具讓慢的孩子撐得住；閃避讓快的孩子打得漂亮 → 兩種流派 | §6.3、§12 |
| 5 | **舊排行被「亂打但很快」的紀錄佔走** | 錯字什麼都不給、正確率門檻、可疑紀錄送老師審 | §18 |

### 3.3 舊排行為什麼會被亂打的紀錄採認

查了程式和資料，原因有三個：

1. **戰績分幾乎不看正確率。** 公式是 `每分鐘正確字數 × 品質 × (0.85 + 0.15 × 正確率)`，
   正確率 34% 只扣 10%。亂敲字、按送出、立刻換下一題，只要偶爾猜中幾個字，速度就衝上去了。
2. **錯的題目照樣算進字數。** 送出時位置對上的字就算「打對」，所以送出一堆半對的答案也能累積字數。
3. **登入畫面的「最高速度」和「最高正確率」是兩場不同比賽各取最高。**
   實際案例：排行第一的紀錄顯示「85 字/分、100%」，但最近一場是 9 字/分、正確率 34%。
   最近一場正確率不到 85% 卻有 15 字/分以上的紀錄有 6 筆，其中一筆最近一場正確率 68%，歷史戰績分卻排全校第 6。

新世界的對策見 §18。建議**原世界的排行也套用其中三條**（同章 §18.5）。

## 6. 狩獵戰鬥

### 6.1 基本規則

- 一場＝一隻大魔物，**時限 5 分鐘**。比原世界的 3 分鐘長，因為魔物血多、會打人、要動腦。
- 打字攻擊跟原世界一樣：Enter 送出、Esc 跳過，三把武器的爆發（詠唱、神射手、連環斬）照舊。
- **只有打對的字有傷害**。整題全錯直接送出，魔物會「反擊」（見 §18.2）。
- 時間內打倒＝討伐成功；時間到＝撤退（有保底）；全隊倒下 3 次＝狩獵失敗（有保底）。

### 6.2 你的生命值與魔物攻擊

新世界的玩家有**生命值**（基礎 100，防具加）。魔物每隔一段時間攻擊一次：

```
魔物頭上出現 ❗ 和 3 秒倒數  →  倒數結束打中你，扣血（防禦越高扣越少）
```

**閃避：倒數期間打完一題而且全對 → 完美閃避，不扣血，下一題傷害 +30%。**

- 生命歸零＝**倒下**：休息 10 秒不能打字，起來後補滿血。
- ★1～★2 的魔物打人很輕，沒穿防具也死不了；★4 以上不穿防具撐不過兩下。

這帶出新世界最重要的流派分歧（對應 §3.2 第 4 點）：

| 流派 | 適合誰 | 怎麼打 |
|---|---|---|
| **鐵壁流** | 打字慢、準 | 堆防禦和生命，不管閃避，穩穩打完 |
| **閃避流** | 打字快 | 堆閃避技能（判定時間更長），每次閃避都吃 +30% |
| **爆發流** | 想打大數字 | 堆攻擊、弱點、爆擊，靠短時間打倒 |

### 6.3 生氣

魔物血量剩一半時**生氣**：畫面變紅、吼一聲，之後攻擊變快、題目長一級，但受到的傷害 +20%。

### 6.4 道具

出發前可以帶最多 **3 個**道具，戰鬥中按 1／2／3 使用（§14.2）。

### 6.5 結算

跟全班討伐一樣的節奏：先播魔物倒下動畫 → 結算畫面。

## 8. 屬性與克制

### 8.1 五種屬性

```
        🔥 火
       ↗     ↘           ☀ 光 ⇄ 🌙 暗
   🌿 木  ←  💧 水          （互相剋制）

  水滅火　火燒木　木吸水
```

- **打弱點：傷害 ×1.5**，跳金色「弱點！」。
- **打到抗性：傷害 ×0.7**，跳灰色「抵抗」。光打光、暗打暗也算抗性。
- 其他組合：×1.0。無屬性武器永遠是 ×1.0。

> 前一版草案說「不做抗性懲罰」。老師這次要強調「武器克制」，所以加回 ×0.7，
> 但不會更重，免得帶錯武器的孩子打不動。

### 8.2 讓孩子知道該帶什麼

- 委託板卡片上寫「**怕 💧**　不怕 🌿」，兩個圖示。
- 出發前，如果你帶的武器剛好是抗性，跳一行提醒：「炎牙狼不怕木屬性，要不要換武器？」（可以忽略）。

### 9.1 六種顏色

| ⬜ 灰 | 普通 | ★1 魔物、商店 |
| 🟩 綠 | 優良 | ★1～★2 魔物、商店 |
| 🟦 藍 | 稀有 | ★2～★3 魔物、商店（貴） |
| 🟪 紫 | 史詩 | ★3～★4 魔物 |
| 🟧 橙 | 傳說 | ★4～★5 魔物、任務 |
| 🟨 金 | 神話 | ★5 稀有掉落、混沌巨龍、主線最終獎勵 |

### 9.2 素材種類

**魔物素材**：每隻魔物 4～5 種，各有固定顏色。範例：炎牙狼

| 素材 | 顏色 |
|---|---|
| 狼毛 | 灰 |
| 狼皮 | 綠 |
| 炎牙 | 藍 |
| 炎狼爪 | 紫 |
| 炎狼心 | 橙 |

**通用礦石**：所有魔物都會掉，商店也賣灰～藍。一種顏色一種：
鐵礦（灰）、銅礦（綠）、銀礦（藍）、秘銀（紫）、星鐵（橙）、龍晶（金）。

**強化石**：強化用，同樣分六色（§10.3）。

合計約 60 種素材加 12 種礦石與強化石，倉庫一頁排 30 格，兩三頁就看完。

### 9.3 素材顏色決定出品品質

這是本企畫最核心的一條規則：

> **做出來的裝備顏色＝你放進去的素材裡「最低」的那個顏色。**
> （但不會低於圖紙的顏色，也不會高於這把裝備的上限。）

範例：炎牙刀（圖紙藍色，上限橙色），配方是「炎牙狼素材（藍以上）×3＋礦石（藍以上）×2」：

| 放進去的 | 做出來 |
|---|---|
| 炎牙×3（藍）＋銀礦×2（藍） | 🟦 藍色炎牙刀 |
| 炎狼爪×3（紫）＋銀礦×2（藍） | 🟦 藍色（銀礦拖累了） |
| 炎狼爪×3（紫）＋秘銀×2（紫） | 🟪 紫色炎牙刀 → 多解鎖一個機制 |
| 炎狼心×3（橙）＋星鐵×2（橙） | 🟧 橙色炎牙刀 |

鍛造畫面上，每個素材格可以自己挑要放哪個顏色，**右邊即時顯示「會做出：🟪 紫色」**。

為什麼用「最低」：孩子一看就懂（一個爛素材會拖累整把），而且結果完全可以預期，不是抽獎。

### 9.4 圖紙

- 魔物掉落，或任務獎勵、商店（只賣灰綠）。
- **學會就永遠會做**，不會用掉。拿到重複的圖紙自動換成字元。
- 圖紙也有顏色，代表這件裝備的**最低品質**。

### 9.5 保底

- 撤退或失敗：仍然拿到 2 個該魔物最低顏色的素材＋依造成傷害比例的字元。
- 同一隻魔物連續 5 場沒掉圖紙，第 6 場必掉一張還沒學會的。

## 10. 鐵匠鋪：鍛造與強化

### 10.1 三個分頁

| 分頁 | 做什麼 |
|---|---|
| ⚒ 鍛造 | 用圖紙＋素材＋字元做出新裝備 |
| ✨ 強化 | 用強化石＋字元讓裝備 +1 |
| ♻ 拆解 | 不要的裝備拆回一半素材 |

### 10.2 鍛造畫面

```
┌──────────────── 鍛造：炎牙刀 ────────────────┐
│  [🟦 圖紙]  匕首・火屬性  上限 🟧                │
│                                               │
│  炎牙狼素材（藍以上）  [🟪炎狼爪] [🟪炎狼爪] [🟪炎狼爪]│
│  礦石（藍以上）        [🟪秘銀]   [🟦銀礦]         │
│                                               │
│  會做出：🟦 藍色　（換一個秘銀就能做紫色！）        │
│  字元：400                                     │
│                  [ 打造！ ]                     │
└───────────────────────────────────────────────┘
```

「換一個 X 就能做更高顏色」這行提示是給孩子的鷹架：他會自己想去刷那個素材。

### 10.3 強化

- **+0 到 +10，一定成功**，不會失敗、不會掉級、不會壞。
- 每 +1：武器攻擊力 +6%，防具防禦 +6%。+10 等於 +60%。
- +5 和 +10 是里程碑：+5 邊框開始發光，+10 名字前面多一顆★。
- 消耗：強化石＋字元。強化石的顏色要 ≥ 裝備顏色（金裝要金強化石），越後面要越多顆。

| 強化 | 強化石 | 字元（以藍裝為例） |
|---|---|---|
| +1～+3 | 每次 1 顆 | 50 / 80 / 110 |
| +4～+6 | 每次 2 顆 | 150 / 200 / 260 |
| +7～+9 | 每次 3 顆 | 330 / 410 / 500 |
| +10 | 5 顆 | 800 |

灰綠裝 ×0.5、紫裝 ×2、橙裝 ×4、金裝 ×8。

> 刻意**不做失敗率**：國小生玩到「強化失敗」只學到賭運氣，也會引來家長疑慮。

## 14. 字元與商店

### 14.1 字元：新世界的錢

### 15.3 組隊結算

跟全班討伐結算同一套畫面：

  刻意放「正確率」獎章，讓打得準的孩子也有舞台。

### 15.4 跟全班討伐的關係

- 老師按「開始比賽」時，**所有房間自動暫停**，全班回原世界打全班 BOSS。

## 17. 獵人等級與星圖天賦

### 17.1 獵人等級 HR

- 狩獵依星等給經驗（★1 20、★2 30、★3 45、★4 65、★5 90；撤退給一半）。主線任務也給。

### 17.2 星圖規則（三條）

1. 從正中間的起點開始。
2. **只能點亮跟已經亮著的星星連在一起的星星**，像連連看。
3. 小星＝一點點數值；大星＝新能力；外圈的皇冠星＝很強，但有一個小代價。

**隨時免費重置。**

## 18. 排行重置與防作弊

### 18.1 新世界排行

所有人從 0 開始，原世界的排行、徽章、紀錄**完全不動**。四個分頁：

| 分頁 | 比什麼 | 鼓勵什麼 |
|---|---|---|
| 獵人等級 | HR | 持續努力 |
| 最快討伐 | 每隻魔物 ★5 的最快秒數 | 技術與配裝 |
| 圖鑑 | 討伐過幾隻、幾星 | 嘗試不同魔物 |
| 精準獵人 | 討伐 ★3 以上時的平均正確率（至少 10 場） | **打得準** |

### 18.2 第一道防線：讓亂打「沒有好處」

與其事後抓，不如讓亂打本身就吃虧：

| 規則 | 效果 |
|---|---|
| 只有打對的字有傷害、經驗、字元 | 亂打賺不到任何東西 |
| **整題錯一半以上就送出 → 魔物反擊**：連擊歸零＋扣 10 點生命 | 亂敲送出會被打倒 |
| 打錯的題目不算進速度 | 送出半對的答案沒有速度可刷 |
| 一題顯示不到 0.4 秒就送出 → 該題無效 | 擋連按 Enter |

### 18.3 第二道防線：排行採計條件

一場要**同時**符合才進排行：

1. 該場正確率 ≥ **90%**。
2. 排行上顯示的速度、正確率、時間**都來自同一場**（修掉 §3.3 第 3 點的問題）。
3. 沒有被下面的偵測標記，或已經被老師核可。

不符合的場次照樣拿掉落、經驗、字元（只看打對的字），**只是不進排行**，
結算畫面會告訴孩子：「這場正確率 82%，要 90% 才能上排行喔」。

### 18.4 第三道防線：可疑紀錄偵測

遊戲在本機記錄每一題的「按鍵次數、送出時間、打對幾個字」，結算時檢查：

| 偵測項目 | 判斷 | 抓什麼 |
|---|---|---|
| 按鍵數太少 | 打出的中文字數 > 按鍵數 ÷ 1.5（注音一個字至少按 2 個鍵） | 貼上、外掛輸入 |
| 速度不合理 | 單題超過每秒 5 個字，或整場超過全校最快紀錄的 1.5 倍 | 異常速度 |
| 節奏太平均 | 每次按鍵的間隔幾乎一樣（像機器） | 連點程式 |
| 數字對不起來 | 雲端寫入的總傷害 ≠ 依每題紀錄重算的總傷害 | 開主控台改數字 |
| 進步太跳 | 這場的速度是自己前 5 場平均的 3 倍以上 | 換人代打 |

被標記的紀錄：

- **不會直接刪除或懲罰**，只是先不上排行。
- 進入教師後台的「**待審核**」清單，附上這場的每題紀錄，老師按「核可」或「不採計」。
- 孩子的結算畫面寫「這場紀錄要等老師確認才會上排行」，不寫「你作弊」。

> 誠實說明：這些檢查都在學生的瀏覽器裡跑，懂技術的人還是能繞過去（見 §22）。
> 它能擋掉的是「亂打但很快」這種最常見的狀況，以及大部分的貼上、連點。

### 18.5 建議原世界也一起修

這三條改起來很小，建議跟 P0 一起做：

1. 戰績分改成 `每分鐘正確字數 × 品質 × 正確率²`（正確率 70% → 只剩 49%）。
2. 正確率低於 85% 的場次不更新歷史最高戰績分。
3. 登入畫面的速度與正確率改成顯示「戰績分最高的那一場」，不再兩場各取最高。

舊紀錄要不要重算，見 §23。

## 20. 資料結構與 Firestore

### 20.1 個人資料：`mg_scores` 多一個 `nw` 物件

```js
nw: {
  hr: 7, hrExp: 140,
  stars: ['c0','pw1','pw2'],                 // 點亮的星
  inv: {                                     // 倉庫
    mats:  { wolf_fang: 3, ore_blue: 5 },    // 素材＝數量
    items: { potion: 2 },                    // 道具
    gear:  [ { id:'g17', base:'flamefang', color:'purple', plus:3 } ]  // 每件裝備
  },
  blueprints: ['flamefang','owl_bow'],       // 學會的圖紙
  equip: { weapon:'g17', head:'g3', body:'g5', hand:null, foot:'g9' },
  loadouts: [ {...}, {...}, {...} ],         // 配裝存檔
  coins: 1240,                               // 字元
  hunts: { wolf: { best: 4, clears: 12, fastest5: 0 } },
  quests: { main: '2-3', daily: { date:'2026-11-03', ids:[...], done:[...] }, ach: [...] },
  title: '好夥伴',
  introDone: true
}
```

Firestore 單一文件上限 1MB，這份最多幾 KB，沒有問題。

### 20.2 新增的集合（**要更新 Firestore 規則**）

| 集合 | 內容 | 讀寫 |
|---|---|---|
| `mg_rooms/{房號}` | 魔物、星等、房主、狀態、開始時間、亂數種子 | 學生可讀寫 |
| `mg_rooms/{房號}/members/{班級_座號}` | 每人的裝備摘要、累計傷害、準備狀態 | 學生可讀寫 |
| `mg_nw_runs/{自動ID}` | 進排行的場次紀錄（含每題摘要） | 學生只能新增 |
| `mg_nw_flags/{自動ID}` | 可疑紀錄 | 學生只能新增 |

> ⚠ 現有規則只開了四個 `mg_*` 集合，**新集合不加規則會被擋**。
> 上線前老師要把新版 `firestore-rules.txt` 重新貼一次，跟第一次上線一樣。

### 20.3 組隊的同步方式

- 每人每 **3 秒**把累計傷害寫進自己的 `members` 文件（不是每打一下就寫）。
- 大家訂閱同一個房間的 `members`，血條＝最大血量－全員累計傷害。
- 用量估算：一場 5 分鐘 4 人房，約寫 400 次、讀 1600 次。
  一個班 6 間房約寫 2,400 次、讀 9,600 次。免費額度是每天寫 2 萬、讀 5 萬，
  **一天大約夠 2～4 個班同時組隊**。超過的話把寫入間隔拉到 5 秒，或只開放同班組隊。

## 22. 風險與對策

| 風險 | 對策 |
|---|---|
| 系統太多，孩子看不懂 | 設施由主線逐一解鎖；每畫面只做一件事；P1 上線就觀察「第二場回來率」 |
| `index.html` 已經 39 萬字，再塞會更難維護 | 新世界拆成獨立的 `newworld.js`（和素材一樣放 GitHub Pages），原世界不受影響 |
| 作弊仍擋不住懂技術的學生 | 單檔網頁做不到伺服器驗證。真的要防，需要 Firebase Cloud Functions（要綁信用卡的付費方案）或改用老師帳號寫入。本企畫先做到「亂打沒好處＋可疑送審」 |
| 身分綁在「班級_座號」，換座號進度就不見 | 教師後台的補償工具（§19）；新學年升級時提供一鍵搬移 |
| 組隊吃掉 Firestore 免費額度 | 3 秒寫一次、可限同班、老師可關；超量時自動拉長間隔 |
| 新世界太好玩，孩子不回原世界練基本功 | 全班討伐仍在原世界；新世界主線有正確率任務；老師可關閉 |
| 英文要切輸入法，孩子卡住 | 偵測到注音就大字提示；英文魔物在主線第 3 章才出現 |
| 數值失衡（某把武器太強） | 每期跑模擬器；P7 用真實資料調整；武器數值集中在一個表 |
