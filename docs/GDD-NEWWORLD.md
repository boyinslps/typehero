## 1. 企畫總覽

### 1.1 一句話

> **原世界練打字，新世界練「怎麼打」**：挑區域和魔物、看牠怕什麼、決定閃避還是防禦、配裝備、打造武器，找出自己的流派。

### 1.2 兩個世界的分工

| | 原世界（現有，不動） | 新世界 |
|---|---|---|
| 主要目標 | 打字速度與正確率 | 配裝、克制、策略 |
| 玩法 | 一路打小怪升級 | 選區域、選一隻大魔物狩獵 |
| 多人 | 全班討伐（老師開） | 組隊房間（學生自己開，最多 4 人） |
| 成長 | 三棵天賦樹 | 裝備＋強化＋星圖天賦（**舊天賦保留，繼續生效**） |
| 排行 | 戰績分 | **從 0 開始**，有防作弊 |
| 打的字 | 共用題庫 | 依魔物不同：注音、詞語、成語、英文、詩句、標點 |

### 1.3 誰能進

**原世界解鎖「史詩」品質（歷史最高 LV8）就能進。** 目前 92 人符合：

| 項目 | 這 92 人 |
|---|---|
| 年級 | 五年級 69、四年級 19、六年級 3、三年級 1 |
| 打字速度 | 中位 14 字/分，後 10% 8 字/分，最慢 6 字/分 |
| 難度層級 | 初階 4、中階 36、高階 19、大師 8（另 25 人沒有層級資料） |

教師後台可以改成「全部開放」或「關閉」。

### 1.4 新世界的難度從哪裡來

不是要求打更快，而是要**動腦**：

- 魔物會讀條攻擊，要判斷**什麼時候打、打「閃避」還是「防禦」**。
- 魔物有**特殊行為**（噴墨遮字、長護盾、隱身…），要帶對應的附加能力。
- 區域和魔物有**屬性**，帶錯武器傷害會打折。
- 高等級魔物有**建議戰力**，裝備沒跟上就打不過，要回去鍛造、強化、打磨。

## 2. 設計原則與用詞

### 2.1 五條底線

1. **一句話講得完。** 講不完就砍。
2. **畫面只顯示一個數字。** 魔物只看「Lv」，裝備只看「攻擊力」「戰力」。
3. **發亮＝可以做。** 能鍛造、能點星、能領獎勵時，那顆按鈕一定會閃。
4. **設施一個一個開。** 由主線任務帶著走（§18）。
5. **不懲罰嘗試。** 強化一定成功、星圖免費重置、撤退也有保底、重新打磨可以留舊的。

### 2.2 隨機的護欄

保留隨機附加能力（§12.4），但加上四道護欄（專家審查共識 3）：

- 重新打磨的結果可以**選留舊的或換新的**，不會失去原本的好能力。
- 重新打磨**每天 10 次**。
- 所有可能的附加能力**公開列出**，不藏機率。
- 同一類加成在全身裝備上有**總上限**。
- **沒有任何東西能用真錢買。**

### 2.3 兒童用詞表

| 不用 | 改用 |
|---|---|
| 詞條 | 附加能力 |
| 弱點／抗性 | 怕／不怕 |
| 重鑄 | 重新打磨 |
| 拆解 | 分解 |
| 機率 | 「會掉」「有機會掉」 |
| 死亡 | 倒下 |

### 2.4 稀有度：顏色＋小點

| 顏色 | 名稱 | 標記 |
|---|---|---|
| ⬜ 灰 | 普通 | ● |
| 🟩 綠 | 優良 | ●● |
| 🟦 藍 | 稀有 | ●●● |
| 🟪 紫 | 史詩 | ●●●● |
| 🟧 橙 | 傳說 | ●●●●● |
| 🟨 金 | 神話 | ●●●●●● |

每個素材、裝備、圖紙的**邊框是顏色，右上角是小點**。色盲的孩子靠數點也分得出來，小點也剛好讓孩子一眼看出「這個比較高級」。

| # | 問題 | 對策 | 章節 |
|---|---|---|---|
| 1 | 一半的孩子玩 1～2 場就沒回來 | 主線帶路、每場有保底、設施逐步解鎖 | §18、§12.6 |

| 4 | 孩子準但慢 | 讀條與有效時間依層級給；防禦好抓，慢的孩子也撐得住 | §7 |
| 5 | **舊排行被「亂打但很快」的紀錄佔走** | 錯字什麼都不給、正確率門檻、可疑紀錄送老師審 | §20 |

### 3.3 舊排行為什麼會被亂打的紀錄採認

1. **戰績分幾乎不看正確率**：`速度 × 品質 × (0.85 + 0.15 × 正確率)`，正確率 34% 只扣 10%。
2. **打錯的題目照樣算字數**：送出時位置對上的字就算打對，送出一堆半對的答案也能累積字數。
3. **登入畫面的最高速度和最高正確率是兩場各取最高**：全校第一的紀錄顯示「85 字/分、100%」，他最近一場卻是 9 字/分、正確率 34%。
   最近一場正確率低於 85% 但速度 15 以上的紀錄有 6 筆，其中一筆最近一場正確率 68%，歷史戰績分卻排全校第 6。

## 5. 初心武器

### 5.1 四選一：三把熟悉的＋一把新的

第一次進新世界時送一把武器。**第 1 段只開放 4 種**，讓孩子先熟悉新世界的讀條、閃避、防禦，不急著換武器：

```
┌──────────────── 選擇你的第一把武器 ────────────────┐
│                                                    │
│  [學徒木杖]       [獵人短弓]      [鐵製小刀]      [木弩]     │
│  法杖・熟悉的！    長弓・熟悉的！   雙刀・熟悉的！   連弩・新的！ │
│  ▶ 動畫預覽       ▶ 動畫預覽      ▶ 動畫預覽      ▶ 動畫預覽  │
│                                                    │
│  每 5 題放一次     集滿爆擊條，     每 5 題一次     打對裝箭，   │
│  「詠唱」         盲打 3 題 ×2    「連環斬」       自己決定    │
│                                                什麼時候射   │
│  ⭐ 你在原世界最常用法杖                                  │
└────────────────────────────────────────────────────┘
                 前 3 場都可以免費換
```

- 原世界的三把標「**熟悉的！**」，最常用的那把再標「⭐ 推薦」。
- 第四把是**連弩**：新世界最直覺的新玩法，看得到彈匣、自己決定什麼時候射。
- 每張卡有 **5 秒動畫**，直接播出這把武器怎麼玩。
- **前 3 場可以免費換**。其他武器之後靠圖紙做出來（§10.4）。
- 初心武器**永遠是這 4 種**，之後開放的新武器不會塞進這個畫面，一次最多四個選項。

### 5.2 之後擴增的武器（候選）

武器彼此獨立、不分系，之後可以一把一把加。擴增的條件：**一定要帶來一種新的操作**，不能只是另一種「打對 X 次觸發 X」。

| 候選 | 新的操作 | 一句話 |
|---|---|---|
| 符咒 | **選題目** | 畫面同時出三張題目卡（短的、中的、帶屬性的），用 ← ↑ → 選一張再打 |
| 回力鏢 | **接回來** | 送出後鏢飛出去，飛回來的那一刻按 Enter 接住才能再丟，沒接到要等它掉地上 |
| 戰鼓 | **跟節奏** | 畫面上有鼓點，在鼓點上按下 Enter 送出，傷害 ×2 |

> 第 6 段之後看哪一種玩法最少人選，再決定先做哪一個。

| 🌑 深淵裂谷 | 黑紫天空、地面裂縫透紫光、黑霧 | Lv42～55 | **暗屬性 +20%** | 夜影貓、熔岩龜、混沌巨龍 | 天空遺跡 ★5 |

- 「某屬性 +20%」是**魔物和玩家都一樣**。到火山，火屬性的魔物更痛，你的火屬性武器也更痛。孩子自然會想：「火山要帶水武器」「火山也可以用火武器硬拚」。
- 同一隻魔物出現在不同區域，**等級不一樣**：咕咕鳥在草原最高 Lv12，在森林可以到 Lv22。

## 7. 狩獵戰鬥（含閃避與防禦）

### 7.1 基本規則

- 一場＝一隻大魔物，**時限 5 分鐘**。
- 打字攻擊的操作跟原世界一樣：Enter 送出、Esc 跳過。
- **只有打對的字有傷害**。整題錯一半以上就送出，魔物會反擊（§20.2）。
- 結果有三種：時間內打倒＝**討伐成功**；時間到＝**撤退**；全隊倒下 3 次＝**狩獵失敗**。撤退和失敗都有保底（§12.6）。

### 7.2 戰鬥畫面：最多 5 個區塊

```
┌──────────────────────────────────────────────┐
│ ① 炎牙狼 Lv25  ▓▓▓▓▓▓▓▓░░░░  （生氣中🔥）       │  ② ⏱ 3:12
│                                              │
│              [ 魔物 ASCII 圖 ]                 │
│         （背景：熔岩火山，火山灰飄落）            │
│                                              │
│ ③ ❤ 生命 ▓▓▓▓▓▓░░ 120/160    ④ 彈匣 ■■■■■■□□□□ 12/20 │
│                                連擊 ×8        │
├──────────────────────────────────────────────┤
│ ⑤ 題目：持之以恆                                │
│   [ 輸入框 ]                                   │
└──────────────────────────────────────────────┘
```

① 魔物（名字、Lv、血條、生氣、讀條、狀態累積條）② 時間 ③ 我的生命＋動作條＋身上的狀態 ④ 能量（依武器不同，§10；連擊縮小放在這裡）⑤ 題目與輸入框。
**不再加第 6 個區塊**（專家審查共識 10）。

### 7.3 讀條、閃避、防禦

魔物要攻擊前會**讀條**：頭上出現一條慢慢變滿的攻擊條，滿了就打下來。

```
炎牙狼 讀條  ▓▓▓▓▓▓▓▓▓░░░ 💥     ← 條滿的那一刻打下來
你的動作              [💨 閃避]   ← 動作的有效時間要蓋住 💥 那一刻
```

**隨時都可以做動作**：在輸入框任何時候打出「閃避」或「防禦」就會發動，不用等提示，打到一半的題目會保留。
每個動作有一段**有效時間**，攻擊打下來的那一刻落在有效時間裡才算成功：

| 動作 | 有效時間 | 動作期間 | 特性 |
|---|---|---|---|
| 💨 閃避 | **短**（中階 1.5 秒） | **不能攻擊** | 要抓準時機；但只停一下，很快就能繼續打 |
| 🛡 防禦 | **長**（中階 4 秒） | **不能攻擊** | 早一點打也來得及；但停比較久，少打幾個字 |

- 動作期間輸入框變灰、不能打字攻擊。自己的生命條下面出現一條**動作條**（閃避短短一截、防禦長長一條），跑完就恢復。
- **太早**：有效時間結束了攻擊才下來 → 全部受傷，還白白停了一下。**太晚**：攻擊已經打中 → 全部受傷。
- 讀條、動作條、💥 命中點都畫在同一個畫面上，孩子看得到「我的條有沒有蓋住那一刻」。

**判定**：

| 攻擊類型 | 讀條外觀 | 有效時間內是「閃避」 | 有效時間內是「防禦」 | 沒有動作／時機不對 |
|---|---|---|---|---|
| 💨 **閃避型**：撲過來、衝撞、跳起來壓 | 紅色讀條＋💨，魔物往後縮蓄力 | **完全不受傷** | 只擋一半 | 全部受傷 |
| 🛡 **防禦型**：大範圍、連打、噴吐 | 藍色讀條＋🛡，魔物身邊冒出波紋 | 只躲一半 | **完全不受傷** | 全部受傷 |

**每隻魔物的攻擊類型比例不同**（§9），有的偏閃避、有的偏防禦，委託卡上會寫。

**這樣設計的取捨**：

| | 閃避 | 防禦 |
|---|---|---|
| 好抓嗎 | 難，要算準什麼時候開始打 | 容易，讀條過一半就可以打 |
| 停多久 | 短 | 長 |
| 適合 | 打字穩又快的孩子 | 打字慢、或速度忽快忽慢的孩子 |

打字慢的孩子用防禦一樣擋得住，只是少打幾個字；打字快的孩子練閃避，停得少、打得多。
再加上攻擊類型（用防禦擋閃避型只擋一半），孩子每次都要決定：**「這下要冒險閃，還是穩穩擋？」**

**三種寫法都接受**，現在用什麼輸入法就打什麼：

| | 中文 | 注音 | 英文 |
|---|---|---|---|
| 閃避 | 閃避 | ㄕㄢˇㄅㄧˋ | jump |
| 防禦 | 防禦 | ㄈㄤˊㄩˋ | stop |

**打英文魔物時的提醒**（老師要求）：

- 出發前跳一張提醒卡：「這隻要打英文！閃避打 **jump**、防禦打 **stop**（中文的『閃避』『防禦』也可以）」。
- 戰鬥中偵測到輸入框是英文時，讀條旁邊和動作條上直接顯示「jump／stop」，不用記。
- 主線 3-1（第一次打英文魔物）開打前，先讓孩子各練一次 jump 和 stop。

> 技術細節：如果題目接下來剛好就是這兩個字（例如英文題裡有 stop），算答題、不算動作。
> 目前題庫裡沒有「閃避」「防禦」這兩個詞，之後加題也要避開。

**成功本身沒有額外效果**，就是不受傷。成功後的效果來自兩個地方：

- **星圖天賦**（§19）：回血、加傷害、提早結束動作…，所以「點閃避區還是防禦區」是一個流派選擇。
- **少數武器把閃避防禦當成主要玩法**（§10）：劍盾防禦成功可以「反擊」、拳套閃避成功進入「爆氣」；拳套不能防禦、大劍不能閃避。

### 7.4 讀條時間、有效時間、攻擊頻率

依孩子的**難度層級**（原世界已經有）決定：

| 層級 | 這群孩子的速度中位 | 讀條時間 | 閃避有效時間 | 防禦有效時間 |
|---|---|---|---|---|
| 初階 | 9 字/分 | 10 秒 | 2.0 秒 | 5 秒 |
| 中階 | 12 字/分 | 8 秒 | 1.5 秒 | 4 秒 |
| 高階 | 16 字/分 | 6 秒 | 1.2 秒 | 3.5 秒 |
| 大師 | 29 字/分 | 5 秒 | 1.0 秒 | 3 秒 |

- 魔物每高 15 級，**讀條**少 1 秒，但初階最短 7 秒、其他最短 4 秒。
- **有效時間不隨魔物等級變**，只有附加能力、套裝、星圖能延長（有總上限，§12.4）。
- 讀條比有效時間長很多，所以就算是最慢的孩子，「讀條一出現就開始打防禦」也來得及（打完時剛好落在有效時間裡的機會很高）。

攻擊頻率：Lv1 每 30 秒一次，Lv55 每 15 秒一次；初階孩子的間隔再乘 1.5。
**目標是「不能攻擊的時間」不超過一場的兩成**。一場 5 分鐘大約被攻擊 10～20 次：全部用防禦大約停 50～80 秒，全部用閃避大約停 20～30 秒，這就是練閃避的回報。

### 7.5 生命、倒下、生氣

- 玩家生命：基礎 100，防具加。受到的傷害會被防禦力減少。
- 生命歸零＝**倒下**：休息 10 秒不能打字，起來後補滿。全隊共用 3 次。
- 魔物血量剩一半時**生氣**：畫面變紅、吼一聲，之後攻擊變快、題目長一級，但受到的傷害 +20%。

### 7.6 道具

出發前最多帶 **3 個**道具，戰鬥中按數字鍵 1／2／3 使用（§16）。

## 8. 屬性、克制、狀態

### 8.1 五種屬性

```
        🔥 火
       ↗     ↘           ☀ 光 ⇄ 🌙 暗
   🌿 木  ←  💧 水          （互相剋）

  水滅火　火燒木　木吸水
```

| 情況 | 傷害 | 畫面 |
|---|---|---|
| 打到魔物**怕**的屬性 | ×1.5 | 金色「怕！」 |
| 打到魔物**不怕**的屬性（光打光、暗打暗也是） | ×0.7 | 灰色「不怕」 |
| 其他、無屬性 | ×1.0 | — |
| 區域屬性加成 | 該屬性 ×1.2（魔物和玩家都一樣） | 區域名稱旁的小圖示 |

- 委託卡寫「**怕 💧　不怕 🌿**」。
- 出發前，如果你的武器剛好是魔物不怕的屬性，跳一行提醒：「炎牙狼不怕木，要不要換配裝？」可以忽略。

### 8.2 三種狀態：燃燒、中毒、寒冰

火、木、水三種屬性各帶一種**狀態**。光和暗沒有狀態，靠互剋取勝。

| 狀態 | 誰會造成 | 圖示 | 一句話 | 魔物中了 | 你中了 |
|---|---|---|---|---|---|
| 🔥 **燃燒** | 火屬性 | 火焰 | 短時間扣很多血 | 5 秒內每秒扣血，合計約 2 題的傷害 | 5 秒內每秒扣 3 點生命 |
| ☠ **中毒** | 木屬性 | 紫色水滴（1～3 顆） | 慢慢扣血，可以疊 3 層 | 15 秒內每秒扣一點，每層合計約 1 題的傷害，最多 3 層 | 15 秒內每秒扣 1 點生命（每層） |
| ❄ **寒冰** | 水屬性 | 雪花 | 變慢 | **讀條變慢一半**，8 秒（讓你比較好抓閃避時機） | **閃避、防禦的有效時間 −30%**，8 秒；輸入框結一層霜 |

**讓魔物中狀態：看得見的三格累積條**

```
炎牙狼 Lv25  ▓▓▓▓▓▓▓▓░░░░   ❄ □■■   ← 再全對 1 題，炎牙狼就會寒冰
```

- 用**藍色以上**的火、木、水屬性武器（灰、綠是無屬性），**每打完一題全對，魔物身上的累積條亮一格**；三格亮滿就中狀態，然後歸零重來。
- 累積條是所有屬性武器共用的背景規則；武器自己的機制（毒箭、荊棘、大浪箭…）可以**直接**讓魔物中狀態，不用等三格。
- 狀態還沒結束時累積條不會再亮（不能疊時間）；**只有中毒可以在結束前再疊一層**，最多 3 層。
- **魔物不會中跟自己同屬性的狀態**：火屬性魔物不會燃燒、水屬性不會寒冰、木屬性不會中毒。委託卡上寫「免疫 🔥」。
- 規則全部可以預期，**沒有機率**：全對三題就一定中。

**魔物讓你中狀態**

- 部分魔物的攻擊帶狀態（§9.1「打中會」那一欄）。
- **完全躲開或完全擋下就不會中**；只擋一半或被打中就會中。這讓「選對閃避還是防禦」多一個理由。
- 狀態會自己消失。想馬上清掉：用道具「**解藥**」（§16.2），或穿有「防燃燒／防中毒／防寒冰」附加能力的防具（1 級時間減半、2 級不會中）。

**三種狀態各自適合誰**

| 狀態 | 適合的打法 |
|---|---|
| 🔥 燃燒 | 想快點打倒魔物：短時間爆發 |
| ☠ 中毒 | 打得穩、能連續全對的孩子：疊到 3 層傷害最高 |
| ❄ 寒冰 | 想練閃避的孩子：讀條變慢，時機比較好抓 |

## 10. 武器種類與玩法

### 10.1 設計原則：每一把都要有自己的「操作」

武器**彼此獨立、不分系**，每一種都帶來一個**別的武器沒有的動作**：

- 有的要在打字**前**先做選擇（元素書）。
- 有的在打字**後**還要抓時機（大劍、連弩）。
- 有的用**閃避或防禦**當主要輸出（劍盾、拳套）。
- 有的讓你可以**不停下來就防禦**（召喚鈴）。
- 有的**改變能用的動作**：拳套不能防禦、大劍不能閃避。

原本的三把維持原世界的玩法，讓孩子有熟悉的起點。

### 10.2 九種武器

| 武器 | 獨特的操作 | 閃避／防禦 | 畫面上看到什麼 |
|---|---|---|---|
| **法杖**（原） | 每 5 題出一次「詠唱」：標點很多的長句，全對 ×3 | 都可以 | 咒語卷軸一行一行寫滿 |
| **長弓**（原） | 打對累積爆擊條，滿了進「神射手」：3 題 ×2，但看不到自己打錯 | 都可以 | 爆擊條、準心 |
| **雙刀**（原匕首） | 每 5 題出一次「連環斬」：一串詞組，打越快越痛 | 都可以 | 刀光一刀一刀閃過 |
| **連弩** | 打對一個字裝一支箭；**輸入框空著時按 Enter，自己決定什麼時候全部射出去** | 都可以 | 彈匣裡的箭一支一支排好，射出去是一整排 |
| **元素書** | **打字前先選元素**：← 火、↑ 水、→ 木；連續兩題換元素會產生**反應** | 都可以 | 輸入框上方三顆元素按鈕，角落有反應表 |
| **劍盾** | 平常傷害低；**防禦成功會跳出「反擊」兩個字，限時內打完＝一記重擊** | 防禦有效時間 +1 秒 | 盾牌擋下時發光，接著一劍刺出 |
| **拳套** | **閃避成功進入「爆氣」4 秒：每打對一個字立刻出一拳，不用按 Enter** | **不能防禦**；閃避有效時間 +0.5 秒 | 拳頭跟著打字的節奏一拳一拳打出去 |
| **大劍** | 送出全對的題目後，跳出**左右擺動的力量條**，再按一次 Enter，停在金色區 ×3 | **不能閃避**（太重了） | 擺錘一樣的力量條，金區揮下巨大數字 |
| **召喚鈴** | 寵物住在武器欄；打「**衝啊**」叫牠攻擊、打「**守護**」叫牠幫你擋下一次攻擊，**你不用停下來** | 都可以 | 左下角原本放武器的地方換成 ASCII 寵物 |

### 10.3 細部規則

**連弩**
- 彈匣 20 支。每支箭的傷害隨「一次射出的支數」變高：存滿再射比較痛，但等太久可能被魔物打斷節奏。
- 一般題目本身的傷害 ×0.5，主要輸出在射箭。

**元素書**
- 輸入框空著、還沒開始打字時，按 **← 火、↑ 水、→ 木**（或數字鍵盤 1、2、3，或直接點按鈕）選元素。不按就沿用上一題的元素。
- 這一題的傷害就是那個元素，打到魔物怕的屬性 ×1.5、累積那個元素的狀態（藍色以上，§8.2）。
- **反應**：上一題和這一題的元素照下面順序接起來，就會觸發。反應表一直顯示在角落：

| 上一題 → 這一題 | 反應 | 效果 |
|---|---|---|
| 🔥 → 💧 | ♨ 蒸氣 | 魔物的讀條暫停 3 秒 |
| 💧 → 🌿 | 🌱 生長 | 你回血 15 |
| 🌿 → 🔥 | 💥 爆炸 | 這一題傷害 ×2.5 |

  孩子每一題都在想：「我現在需要爆炸、回血，還是讓牠停下來？」再加上魔物怕什麼，選擇很豐富。

> ⚠ **按鍵注意**：注音輸入法開著的時候，鍵盤上排的 1、2、3 是 ㄅ、ㄉ、ˇ，按下去會開始組字。
> 所以元素書用**方向鍵**或**數字鍵盤**選元素，上排數字只有在英文模式下才算數。畫面上的三顆按鈕也可以直接點。

**劍盾**
- 一般題目傷害 ×0.6；防禦有效時間比別人多 1 秒。
- 防禦成功後，輸入框跳出發光的「**反擊**」（英文模式打 **hit**），限時內打完＝反擊，傷害等於 4 題。
- 反擊限時依層級：初階 6 秒、中階 5 秒、高階 4 秒、大師 3 秒。
- **完美格擋**：讀條最後 1 秒內才擋下＝反擊傷害 ×2，盾牌閃金光。
- 劍盾讓孩子**主動去等魔物攻擊**，偏防禦的魔物（熔岩龜、海盜章魚）是劍盾的主場。

**拳套**
- **不能打「防禦」**，只能閃避；閃避有效時間比別人多 0.5 秒。
- 閃避成功進入**爆氣** 4 秒：這段時間每打對一個字就立刻出一拳造成傷害，不用等整題打完、也不用按 Enter。
- 一般題目照常計算。偏閃避的魔物（炎牙狼、詩仙鶴、夜影貓）是拳套的主場。

**大劍**
- **不能打「閃避」**，只能防禦。
- 送出一題全對後，題目區跳出一條左右擺動的力量條，再按一次 Enter 停下：

```
 [ 灰 | 黃 | ★金★ | 黃 | 灰 ]
            ▲ 擺動中，按 Enter 停下
 灰 ×1　黃 ×2　金 ×3
```

- 力量條擺動速度依層級：初階最慢。沒全對的題目沒有力量條。
- 一般題目沒有額外傷害倍率，輸出全看「全對＋抓準時機」。

**召喚鈴**
- 寵物住在左下角原本放第一人稱武器的位置（ASCII 畫），**不多佔畫面**。
- 每打對 1 個字，寵物體力 +1；10 點一格，最多 3 格，顯示在寵物頭上。
- 指令（跟閃避、防禦一樣，在輸入框隨時打）：

| 指令 | 英文 | 花費 | 效果 |
|---|---|---|---|
| 衝啊 | go | 1 格 | 寵物撲上去攻擊，傷害等於 2 題，帶寵物的屬性 |
| 守護 | help | 2 格 | 寵物擋在你前面，**下一次攻擊不管哪一種都完全擋下**，你可以繼續打字 |

- 「守護」是召喚鈴的核心：別人防禦要停下來，召喚鈴的孩子可以一直打字。代價是要先存體力，時機也要自己判斷。
- 自動傷害有上限：寵物一場造成的傷害不超過本場打字傷害的 40%。

### 10.4 什麼時候拿到

| 武器 | 怎麼拿 | 開放 |
|---|---|---|
| 法杖、長弓、雙刀、連弩 | 初心武器四選一，其他三把的灰色圖紙在主線第 1 章送 | 第 1 段 |
| 劍盾、拳套 | 森林的魔物掉圖紙；主線第 2 章任務送一張 | 第 2 段 |
| 元素書 | 海岸的魔物掉圖紙 | 第 3 段 |
| 大劍、召喚鈴 | 火山、雪原的魔物掉圖紙 | 第 5 段 |

### 10.5 指令字一覽

畫面上會一直顯示目前能用的指令（小標籤），不用背：

| 指令 | 誰能用 | 英文 |
|---|---|---|
| 閃避 | 所有武器（大劍除外） | jump |
| 防禦 | 所有武器（拳套除外） | stop |
| 反擊 | 劍盾，防禦成功後 | hit |
| 衝啊、守護 | 召喚鈴 | go、help |
| 看我 | 聖光騎士盾（組隊） | me |

> 題庫裡已經查過，「反擊」「衝啊」「守護」「看我」都沒有出現在題目裡；「保護」有出現（保護環境），所以召喚鈴改用「守護」。之後加題也要避開這幾個詞。

### 10.6 美術

- **魔物和武器都是 ASCII**，跟原世界一樣放在 `assets/` 的純文字檔，老師可以自己改。
- 每種武器一張第一人稱 ASCII（9 張）＋三組攻擊特效；同一種武器的不同屬性版本**用顏色區分**（火紅、水藍、木綠、光金、暗紫），不用每把各畫一張。
- 召喚鈴的寵物也是 ASCII：史萊姆、小樹精、小黑龍各一張，放在武器欄。
- 魔物 12 隻各一張 ASCII，生氣時換色。
- 區域背景用 CSS 漸層，飄落的粒子也用 ASCII 字元（雪花 `*`、落葉 `,`、火山灰 `.`、泡泡 `o`）。
- 克制表、狀態圖示、反應表、按鈕這些介面元素用 emoji。

## 12. 稀有度、素材、圖紙、附加能力

### 12.1 素材

**魔物素材**：每隻魔物 4～5 種，各有固定顏色。範例：炎牙狼

| 素材 | 顏色 |
|---|---|
| 狼毛 | ⬜● |
| 狼皮 | 🟩●● |
| 炎牙 | 🟦●●● |
| 炎狼爪 | 🟪●●●● |
| 炎狼心 | 🟧●●●●● |

**通用礦石**：所有魔物都會掉，商店也賣灰～藍：鐵礦 ⬜、銅礦 🟩、銀礦 🟦、秘銀 🟪、星鐵 🟧、龍晶 🟨。

**強化石**：強化和重新打磨用，同樣分六色。

### 12.2 素材顏色決定裝備顏色

> **做出來的裝備顏色＝放進去的素材裡「最低」的那個顏色。**
> （不會低於圖紙的顏色，也不會高於這件裝備的上限。）

範例：炎牙刀（圖紙藍色、上限橙色），配方是「炎牙狼素材（藍以上）×3＋礦石（藍以上）×2」：

| 放進去的 | 做出來 |
|---|---|
| 炎牙×3（藍）＋銀礦×2（藍） | 🟦 藍色 |
| 炎狼爪×3（紫）＋銀礦×2（藍） | 🟦 藍色（銀礦拖累了） |
| 炎狼爪×3（紫）＋秘銀×2（紫） | 🟪 紫色 → **第一次有武器機制**、多一個附加能力 |
| 炎狼心×3（橙）＋星鐵×2（橙） | 🟧 橙色 |

### 12.3 顏色帶來什麼

| 顏色 | 武器帶來什麼（§14） | 附加能力數量 |
|---|---|---|
| ⬜ 灰 | 只有數值，無屬性 | 0 |
| 🟩 綠 | 只有數值，無屬性 | 1 |
| 🟦 藍 | **屬性＋狀態**（🔥燃燒／☠中毒／❄寒冰，§8.2） | 1 |
| 🟪 紫 | **機制 ①** | 2 |
| 🟧 橙 | 機制 ② | 3 |
| 🟨 金 | 機制 ③ | 3＋1 個金色專屬能力 |
| 🟨 金 **+10** | **覺醒** | — |

**藍色第一次有屬性和狀態**：藍色素材 Lv10 以上就會掉（森林），孩子很快就能用火燒、用毒疊、用水冰。
**紫色才第一次有「改變操作」的機制**：紫色素材要打 Lv20 以上的魔物才開始掉，中位孩子大約玩到第 3 段（海岸、火山）才拿得到，機制成為中期的大目標。
覺醒要金色裝備再強化到 +10，是一學期的長期目標。

**顏色由素材決定（可以預期），附加能力的內容隨機（有驚喜）。**

**總上限**（全身加起來）：攻擊類 +40%、爆擊機率 +30%、閃避有效時間 +0.6 秒、防禦有效時間 +2 秒、字元與素材各 +50%。

### 12.5 圖紙

- 魔物掉落、任務獎勵、商店（只賣灰綠）。屬性武器的圖紙從**同屬性的魔物**身上掉。
- **學會就永遠會做**，不會用掉。重複的圖紙自動換成字元。
- 圖紙的顏色＝這件裝備的最低顏色。

### 12.6 保底

- 撤退或失敗：仍然拿到 2 個該魔物最低顏色的素材，加上依造成傷害比例計算的字元。
- 同一個區域連續 5 場沒掉圖紙，第 6 場必掉一張還沒學會的。

- 每種武器 3 把，共 **27 把**：

  - **進階**：有屬性，藍～橙。藍色＝屬性與狀態，紫＝機制 ①，橙＝機制 ②。

### 14.13 武器熟練度

武器不分系，所以每一種武器有**自己的熟練度**：用它狩獵就會累積，1～5 顆星。

- ★5 給稱號（例如「盾反大師」），並在流派徽章上多一圈金邊。
- 這讓孩子**換一把新武器也有東西可以練**，不會因為主武器很強就不想試別的。

|---|---|
| 只有打對的字有傷害、經驗、字元 | 亂打賺不到任何東西 |
| **整題錯一半以上就送出 → 魔物反擊**：連擊歸零＋扣 10 點生命 | 亂敲送出會被打倒 |
| 打錯的題目不算進速度 | 送出半對的答案刷不了速度 |
| 一題顯示不到 0.4 秒就送出 → 這題無效 | 擋連按 Enter |

### 20.3 第二道防線：排行採計條件

一場要**同時**符合才進排行：

1. 這場正確率 ≥ **90%**。
2. 排行上的速度、正確率、時間**都來自同一場**。
3. 沒有被第三道防線標記，或已經被老師核可。

不符合的場次照樣拿掉落、經驗、字元，只是不進排行。結算畫面會說：「這場正確率 82%，要 90% 才能上排行喔」。

### 20.4 第三道防線：可疑紀錄偵測

遊戲在本機記錄每一題的「按鍵次數、送出時間、打對幾個字」，結算時檢查：

| 偵測 | 判斷 | 抓什麼 |
|---|---|---|
| 按鍵太少 | 打出的中文字數 > 按鍵數 ÷ 1.5（注音一個字至少 2 鍵） | 貼上、外掛輸入 |
| 速度不合理 | 單題超過每秒 5 字，或整場超過全校最快紀錄的 1.5 倍 | 異常速度 |
| 節奏太平均 | 每次按鍵的間隔幾乎一樣 | 連點程式 |
| 數字對不起來 | 寫進雲端的總傷害 ≠ 用每題紀錄重算的總傷害 | 開主控台改數字 |
| 進步太跳 | 這場速度是自己前 5 場平均的 3 倍以上 | 換人代打 |

被標記的紀錄**不刪、不罰**，先不上排行，送進教師後台「待審核」，附上每題紀錄，老師按「核可」或「不採計」。
孩子的結算畫面寫「這場紀錄要等老師確認才會上排行」，**不寫「作弊」**。

> 誠實說明：這些檢查在學生的瀏覽器裡跑，懂技術的人還是繞得過去（§24）。
> 擋得掉的是「亂打但很快」這種最常見的狀況，以及大部分的貼上與連點。

### 20.5 原世界一起修（第 0 段）

1. 戰績分改成 `速度 × 品質 × 正確率²`（正確率 70% → 只剩 49%）。
2. 正確率低於 85% 的場次不更新歷史最高戰績分。
3. 登入畫面的速度與正確率改成顯示「戰績分最高的那一場」。

## 21. 分段開放與「施工中」

### 21.1 兩種鎖，長得完全不一樣

| | 🔗 施工中 | 🔒 任務解鎖 |

| 文字 | 「施工中・第 N 段開放」 | 「完成主線 1-5 開放」 |
| 點了會 | 跳出預告卡：一張示意圖＋一句話（「鐵匠鋪：可以打造自己的武器！」） | 跳出任務說明，按鈕直接帶去接任務 |

```
┌─────────────┐   ┌─────────────┐
```

### 21.2 先存著：還沒開放的獎勵不會浪費

鐵匠鋪一開張，孩子手上已經有一堆素材可以用，開幕當天就能打造。這也讓施工中的設施變成**期待**而不是空牆。

## 23. 資料結構與 Firestore

### 23.1 個人資料：`mg_scores` 多一個 `nw` 物件

```js
nw: {
  hr: 7, hrExp: 140,
  starter: 'crossbow', starterSwaps: 1,      // 初心武器、已換次數
  stars: ['c0','dg1','dg2'],                 // 點亮的星
  coins: 1240,                               // 字元
  mats:  { wolf_fang: 3, ore_blue: 5 },      // 素材＝數量

             affix:[['atk',8],['vsWater',6]] } ],   // 每件裝備
  blueprints: ['flamefang','owl_bow'],       // 學會的圖紙
  equip: { weapon:'g17', head:'g3', body:'g5', hand:null, foot:'g9' },
  loadouts: [ {...}, {...}, {...} ],         // 配裝存檔
  mastery: { crossbow: 2, shield: 1 },       // 每種武器的熟練度（1～5）
  zones: { grass: 5, forest: 3 },            // 每個區域打到的最高星等
  hunts: { wolf: { clears: 12, fastest: { forest: 0 } } },
  quests: { main: '2-3', daily: [...], ach: [...] },
  polishToday: { date: '2026-11-03', n: 3 }, // 重新打磨次數
  title: '好夥伴'
}
```

單一文件上限 1MB，這份最多十幾 KB，沒有問題。

### 23.2 新增的集合（**要更新 Firestore 規則**）

| 集合 | 內容 | 讀寫 |
|---|---|---|
| `mg_rooms/{房號}` | 區域、魔物、星等、房主、狀態、開始時間、亂數種子 | 學生可讀寫 |
| `mg_rooms/{房號}/members/{班級_座號}` | 流派、戰力、累計傷害、準備狀態 | 學生可讀寫 |
| `mg_nw_runs/{自動ID}` | 進排行的場次紀錄（含每題摘要） | 學生只能新增 |
| `mg_nw_flags/{自動ID}` | 可疑紀錄 | 學生只能新增 |

> ⚠ 現有規則只開了四個 `mg_*` 集合，**新集合不加規則會被擋**。
> 第 1 段（排行與可疑紀錄）和第 4 段（房間）上線前，老師要把新版 `firestore-rules.txt` 重新貼一次。

### 23.3 組隊同步

- 每人每 **3 秒**把累計傷害寫進自己的 `members` 文件。
- 大家訂閱同一個房間的 `members`，血條＝最大血量－全員累計傷害。
- 用量估算：一場 5 分鐘 4 人房約寫 400 次、讀 1,600 次；一個班 6 間房約寫 2,400 次、讀 9,600 次。
  免費額度每天寫 2 萬、讀 5 萬，**一天大約夠 2～4 個班同時組隊**。超過就把間隔拉到 5 秒，或只開同班組隊。

## 24. 風險與對策

| 風險 | 對策 |
|---|---|
| 系統太多，孩子看不懂 | 分段開放；主線逐一帶；每畫面只做一件事；第 1 段上線後看「第二場回來率」 |
| 隨機附加能力讓孩子停不下來 | 可以留舊的、每天 10 次、清單公開、總上限、沒有真錢 |
| 閃避防禦的時機抓不到 | 讀條與有效時間依層級給；防禦有效時間長、先教防禦；三種寫法都接受；上線後看各層級的成功率，低於六成就再放寬 |
| 9 種武器數值失衡 | 種類係數集中在一張表；自動傷害上限 40%；模擬器＋上線後資料 |
| `index.html` 已經 39 萬字 | 新世界拆成獨立的 `newworld.js` 和 `assets/nw/`，原世界不受影響 |
| 作弊仍擋不住懂技術的學生 | 單檔網頁做不到伺服器驗證；真要防需要 Firebase Cloud Functions（要付費方案）或老師帳號寫入 |
| 身分綁在「班級_座號」 | 教師後台補償工具；新學年提供一鍵搬移 |
| 組隊吃掉免費額度 | 3 秒寫一次、可限同班、老師可關、超量自動拉長間隔 |
| 組隊排擠 | 不能踢人、快速加入、沒有聊天、多元獎章 |
| 孩子不回原世界練基本功 | 全班討伐仍在原世界；新世界有正確率任務；老師可關閉 |
| 施工中太多，覺得遊戲沒做好 | 第 1 段就有完整循環；施工中可以點開看預告；獎勵先存著 |
| 舊電腦跑不動背景粒子 | 粒子數量上限，設定裡可以關 |
