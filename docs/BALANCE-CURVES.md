## 先講限制（請先讀）

1. **真實速度分布還沒拿到。** 速度用 `BALANCE.md` §0 的 139 筆實測（p25=6、中位 10、p75=14、p90=19）擬合的對數常態（σ=0.65）。老師匯出後跑 `--real`（§1.4）就會全部重算。對數常態在左尾不太準：擬合的 p10 是 4.3，實測是 3（實測左尾更長）。
2. **戰鬥模型是期望值近似，不是模擬。** 每個字獨立打錯；連擊用穩態；燃燒／中毒／寒冰不算；武器特技（詠唱、神射手、連環斬、連射）取週期平均；材料只分顏色不分魔物。它用來**先把曲線定出形狀**，最後要交給升級後的模擬器（§6）用 1,000 場覆核。
3. **最大的未知是「bestWpm 換算成戰鬥中速度」的係數 α=0.6375**（沿用 `sim.mjs` 的 `avgOfBest 0.75 × dual 0.85`）。敏感度分析（§5）裡它跟速度本身一樣是第一名：±20% 讓「慢」打炎牙狼★1 的勝率在 21%～89% 之間擺。`mg_nw_runs` 開始寫之後，每場的 `cpm` 可以直接校正它。
4. **三線戰鬥的反應時間是猜的**（新手 1.0 秒、標準差 0.35，沿用 `SPEC-STAGE2` §3.4）。舊模擬器的「打字閃避」假設是 2.2 秒，兩者差很多。
5. **舊模擬器 `sim.mjs` 的缺陷仍在**：舊的打字閃避模型、每隻都當成會攻擊、沒有防具、persona 速度（11～53）比實測高很多（`BALANCE-REFS` §5.1 已指出）。這份文件的勝率**不能**和 `SPEC-STAGE2` §3.4 的粗跑表直接比。
6. 學生「挑哪一隻、先做哪件」的策略（§4.1）是假設的，真實孩子會更亂。

## 1. 玩家模型

### 1.1 速度分布（參數化）
- 單位：**每分鐘正確字數**（舊世界 `bestWpm`，國字）。`ln v ~ N(μ, σ²)`，中位 `e^μ = 10`、`σ = 0.65`（研究 §2.2 擬合 0.63～0.72）。
- 三組學生（`P.persona`）：慢＝p25＝6、中＝p50＝10、快＝p90＝19；G1 另用實測最高 45（極快）。
- 層級：教學量到的速度 ≈ `0.75 × bestWpm`（`BALANCE.md` §7.3），門檻 <6 A、<14 B、<28 C、其餘 D。所以 **慢＝A、中＝B、快＝C**（已驗算，附錄 A1）。
- 正確率：逐字 0.95／0.97／0.98（假設。實測「場次正確率」中位 100%，逐字一定低一點）。
- 學期內成長：線性 +15%（`P.growth`，研究 §5.2 的 +4.5 字/分／24 週「待核」，我取保守值）。

### 1.2 一場戰鬥怎麼打題
```
戰鬥中速度   c = α · v          α = 0.6375（＝0.75 平均/最好 × 0.85 雙工）
一題耗時     t_q = 60·L/c + τ0   τ0 = 0.5 秒（送出、看下一題）
題長 L       依魔物等級、星級、生氣（現行詞庫實測平均）：
             Lv<20 → 2.0 字；生氣後在 Lv≥10 換 epic 池 3.75 字；Lv≥20 平時 3.75、生氣 legend 6.19（★5）
一題傷害     d · E[算傷害的字] · ω · κ · g · (生氣 ×1.2)
             d = perChar 9；E[算傷害的字] 用二項分布：打錯 ≥ 一半＝0 傷害並被反擊 10 生命
             ω = 武器種類係數（§3.2）；κ = 連擊；g = 裝備攻擊倍率
連擊         κ_完美 = 1 + 0.02·Σ_{k=1..20} p^(k−1) = 1 + 0.02·(1−p^20)/(1−p)，p = a^L（一題全對機率）
```
- 題長是我用 `assets/banks/common_*.json` 算的：normal、fine 平均都是 2.0 字，epic 3.75，legend（≤6 字）5.32、（≤8 字）6.19。**所以現在幾乎所有關卡都是 2 字詞**，`MAX_CHARS`（4／6／8）只在 Lv≥20 才真的起作用（已驗算，附錄 A1「題長」欄）。
- 連擊 κ（題長 2）：正確率 0.95／0.97／0.99 → 1.18／1.24／1.33（已驗算）。

### 1.3 受傷事件
```
出招次數   n ≈ 1 + (T_活動 − 6 − 讀條)/間隔            間隔 = atkInterval(lv,層級)，咕咕鳥 ×0.6、狼生氣 ÷2
被打中     每次出招被打中的機率 h = Σ 招式權重 × P(在危險線) × (1 − P(躲開))
           P(來得及) = Φ((預警 − 0.15 − 反應平均)/反應標準差)；預警 = LANE_W[層級] + 護腳
           夾擊另乘「選對安全線」0.8～0.95；重壓：舉盾太早（反應 < 預警−盾秒數）時，50～90% 的人會再按一次
被打中次數 X ~ 二項(n, h)；失去生命 = X·D·(1−受傷少) + 亂打次數·10
倒下次數   floor(失去 / 生命上限)，3 次＝失敗；每次倒下 10 秒不能打字
```

## 2. 戰鬥模型（解析式）

### 2.1 不攻擊的魔物（現行跳跳菇、炎牙狼）
```
傷害率     r(v, g) = d·E·ω·κ·g / t_q(v)                （平靜與生氣兩段各算）
打完時間   T(v, g) = (H/2)/r_平靜 + (H/2)/r_生氣 + 倒下×10
門檻速度   v_need(g)：T(v_need, g) = 300
勝率       P(贏 | v) = Φ( ln(v / v_need) / σ_b )         σ_b = 0.20（同一個人場與場的手感差，假設）
全班勝率   ∫ P(贏 | v) dF(v)                            （對數常態 400 個等機率點，或真實名單）
```

### 2.2 裝備把門檻乘以 1/g
若 τ0 = 0，`r ∝ c·g`，所以 `v_need(g) = v_need(1)/g`。有 τ0 時：
```
v_need(g) / v_need(1) = (A − τ0) / (g·A − τ0)      A = 門檻那一刻每題的總耗時（約 20～40 秒）
```
比 1/g 還小一點（裝備效果略強），但 τ0/A ≈ 2%，所以實務上 **= 1/g**。腳本算出 g=1.05／1.10／1.20／1.32 → 0.95／0.91／0.83／0.76，跟 1/g 到小數第二位一樣（已驗算，附錄 A2）。

推論（研究 §2.2 的三個結論，在這個模型下都成立）：
1. 裝備只移動門檻，不改 S 形曲線的斜率；**同一層級內**，速度比 ρ 的兩人只有 `g_慢/g_快 ≥ ρ` 才會顛倒。
2. 一隻魔物被裝備「翻盤」的人數上限 `≈ ln g / (σ_總 √2π)`，σ_總 = √(σ²+σ_b²)：g=1.32 → 16.3%（已驗算）。實際算出：炎牙狼★5 全班勝率 47% → 62%（+15pp）、★1 76% → 86%（+10pp）（已驗算，附錄 A2）。
3. 慢的孩子主要輸在**時間到**（現行規則下他們幾乎不倒下），所以能救他們的是血量層級與武器，不是防具（§3.4）。

### 2.3 會攻擊的魔物
```
T = T_打字 + n·P(要動作)·0.3 秒 + E[倒下]·10        （n 又取決於 T，迭代 4 次收斂）
P(贏) = Φ(ln(v/v_need)/σ_b) × (1 − P(倒下 3 次))
```
結果（現行數值，已驗算，附錄 A2、A3）：
- **草原的攻擊幾乎傷不到人**：咕咕鳥每場被打中 0.2～0.5 次、失去 4～9% 生命；泡泡蛙重壓失去 14～25%。原因是預警（A 層 3.0 秒、B 層 2.5 秒）比反應時間長很多，加上咕咕鳥一下只有 4～12 傷害。
- **狼如果開攻擊**，★5 中位學生失去 76% 生命、倒下 0.2 次；勝率從 34% 掉到 30%。**狼★5 的難度主要來自血量，不是攻擊**。

## 3. 曲線設計

### 3.1 魔物血量：對星級、區域、層級
**現行公式**（不改型）：`H = (440 + 20·Lv) · hpMul · HP_TIER[層級]`，`Lv = 區域下限 + (上限−下限)·(★−1)/4`。

**為什麼留線性**：`BALANCE.md` v3 已證明飽和曲線後期沒壓力；而且把它換成「門檻速度 ÷ 層級代表速度」（壓力比 θ）來看，現行數字**已經是一條等比階梯**：

| B 層（代表速度 11.8） | 草原 咕咕鳥★1 | 跳跳菇★3 | 跳跳菇★5 | 森林 炎牙狼★1 | 炎牙狼★3 | 炎牙狼★5 |
|---|---|---|---|---|---|---|
| 門檻 v_need | 3.8 | 5.6 | 6.8 | 7.4 | 8.8 | 10.9 |
| 壓力比 θ | 0.32 | 0.47 | 0.58 | 0.63 | 0.75 | 0.92 |

`(0.92/0.32)^(1/9) = 1.125`：**每升一星，門檻速度約 +12%**（已驗算，附錄 A1），高於一般 JND，和研究 §7.2 建議的「每星 +20～30% 血量」方向一致（血量 +12% 已經讓門檻 +12%，因為 r 對 v 幾乎是線性）。

**問題在層級之間不公平**：讓各層級「代表速度」的壓力一樣，倍率應該是

| 層級 | 代表 bestWpm | 現行 | 公平倍率 | 建議（第 3 段前） |
|---|---|---|---|---|
| A | 5.3 | 0.35 | 0.23 | **0.30** |
| B | 11.8 | 0.50 | 0.50 | 0.50 |
| C | 25.9 | 0.70 | 1.07 | **0.80** |
| D | 46.7 | 1.70 | 1.85 | 1.70 |

（公平倍率已驗算，附錄 A1。）A 層現在比 B 層難約 1.5 倍、C 層比 B 層容易約 1.5 倍。**我不建議一次調到公平值**：A 改到 0.25 時，「慢（A 層、6 字/分）」打咕咕鳥★1 要 105 秒，比「中（B 層、10 字/分）」的 116 秒還快，次序倒過來（已驗算，附錄 A5）。A 0.30、C 0.80 是「往公平走、但同一隻魔物仍然 快 < 中 < 慢 秒數」的折衷（已驗算：咕咕鳥★1 94／116／126 秒，附錄 A5）。

**之後的新區域**（第 3 段起；設計提案）：
```
H(區域 k, ★s) = H(森林★1) · G_exp(k) · S_grow(k) · 1.12^(s−1)
G_exp(k) = 進第 k 區時「預期裝備」的攻擊倍率（§3.2 表：1.06、1.17、1.28、1.41）
S_grow(k) = 到第 k 區時預期的速度成長（每學期 ×1.15，假設）
```
意思是：**帶著該區預期裝備、長大了一學期的孩子，進新區時的壓力跟第一次進森林一樣**（Rosewater 的 Escher 樓梯，研究 §1.1）。數字可以照 GDD §14.12 變大，壓力不變。

### 3.2 武器傷害：顏色、強化、種類
```
攻擊力(顏色 c, +n) = A_c · (1 + 0.02·n)      第 2 段：A = 灰 100、綠 105、藍 110（每 +1 = +2）
之後：A_c = 100 · 1.10^c（灰/綠 100、藍 110、紫 121、橙 133、金 146）
g = 攻擊力/100 × 屬性（怕 ×1.1、不怕 ×0.9）  上限：同一區域內 g_max / g_進區 ≤ 1.33
```
- **為什麼是 +2%／級、×1.10／階**：這樣「同區最強（+5 × 屬性）÷ 上一階 +0」固定是 `1.10 × 1.10 × 1.10 = 1.33`（已驗算，附錄 A4 future 表），剛好等於第 2 段的 ×1.32 預算。數字一直變大，區域內的差距不變。
- 第 2 段的 100／105／110 是這條曲線的「半階版」（每階 5%），可以照用。
- 強化 +1 的手感：G2 解析值「+0→+1 少 1.9% 時間」（已驗算），低於 JND，**畫面要寫「少 N 秒」**（研究 §1.2）。
- **HR 不加傷害**（設計決定）：HR 只給星圖星星；星圖的傷害加成之後要算進同一個 g 上限（例如最多 +5%，從武器上限裡扣），不另開一層乘法（研究 §2.1「同類相加、類別相乘，全遊戲只允許兩層」）。

**武器種類係數 ω（重要發現，推論，要模擬覆核）**：照 `nw-battle.js` 的規則取期望值（中速、正確率 97%、2 字詞）：

| 法杖 | 長弓 | 雙刀 | 連弩 |
|---|---|---|---|
| 1.48 | 1.57 | **1.08** | 1.64 |

（已驗算，附錄 A1。）四把的差距 1.64/1.08 = **×1.52，比整套裝備的預算 ×1.32 還大**。雙刀的連環斬倍率 `1.2 + 0.5×字/秒`，對每秒只打 0.1～0.3 字的孩子幾乎只有 ×1.25，又只有 1/5 的題目會觸發。如果模擬器證實，**選錯初心武器的影響比裝備大**，要先修雙刀（例：`flurrySlope` 改看「字/分」、或雙刀 ×0.95 改 ×1.05），再談裝備。

### 3.3 裝備五格：疊加規則與上限

| 格 | 灰 | 綠 | 藍 | 每 +1 | 上限 | 疊加 |
|---|---|---|---|---|---|---|
| 武器 攻擊力 | 100 | 105 | 110 | +2 | g ≤ 1.32 | 武器 × 屬性（全遊戲唯一的乘法） |
| 頭盔 生命 | +10 | +20 | +30 | +2 | +60 | 加法 |
| 盔甲 受傷少 | 4% | 7% | 10% | +1% | 30% | 加法；超過 30% 的部分改 `d/(1+d)`，永遠到不了 100%（研究 §2.1） |
| 護手 舉盾 | +0.2 | +0.3 | +0.4 | +0.04 秒 | +1.0 秒 | 加法 |
| 護腳 預警 | +0.10 | +0.20 | +0.30 | +0.03 秒 | +0.6 秒 | 加法 |

**「裝備佔比」20% 要不要改**：用擬合分布 p10～p90（4.3～23，5.3 倍）算，g=1.32 是 17%、g=1.50 是 24%（已驗算）。研究 §2.2 用實測 3～19（6.3 倍）算是 15%。我的檢討：
- 20% 本身沒有來源（研究標了推論），但它換成白話是「裝備最多抵掉 p10 到 p90 這段手速差的五分之一」，對「手快不能被蓋過」是合理的天花板（經驗判斷）。
- **比 20% 更該盯的是兩件事**：① 同一層級內的次序保留（`g_max < 下一個速度群的比值`，研究 §2.2 第 4 點）；② 上面的武器種類差距 ×1.52——它不在 g 裡，卻比 g 大。
- 所以建議**保留 20% 當上限、第 2 段實際用 17%**，並把「武器種類 ω 的最大/最小 ≤ 1.15」加進驗收（設計決定）。

### 3.4 防具：現行規則下幾乎沒有作用
解析結果（已驗算，附錄 A3）：
- 慢（A 層）咕咕鳥★5 夾擊：無裝備躲開 87%，綠護腳 +3 還是 87%（G6 要 +10pp，**不過**）。失敗主要是「選錯安全線」，不是來不及；A 層 3.0 秒預警已經比反應時間長很多。
- 泡泡蛙★3 重壓：70% → 綠護手 +3 72%（**不過**）。
- 咕咕鳥★5「倒下少 30%」：本來就 0 次倒下，**無法驗收**。
- 把反應改成舊模擬器那種 2.0 秒（`--set react.0=2.0 --set react.1=1.4 --set reactSd=0.6`）：重壓 82% → 90%、夾擊 85% → 87%，仍然不過。

**建議**（設計決定）：
1. 草原的攻擊維持「教學用、不太痛」，**對外說明防具「讓你更安心」而不是「沒有它會輸」**。
2. 防具的價值放在森林（狼開攻擊後）：狼現行傷害就符合 D5 的 λ 曲線（★1 需要 ×1.3、★5 需要 ×1.6 才剛好，見附錄 A3 ttd 表），**不必再加傷害**。
3. 要讓護腳有意義，只能讓預警變緊：提案「每升一星預警 −8～10%」（`--set winShrink=0.1` 可算），★3 起的「掃線」「假動作」才會用到反應時間。先用遙測 `dodgeOk/dodgeAll` 確認真實反應時間再決定（反應時間是 §5 最不確定的假設之一）。

### 3.5 屬性相剋
- ×1.1／×0.9 對稱（研究 §2.1：溫和相剋仍是對稱的 RPS）。打對與打錯差 1.1/0.9 = 1.22 倍，**屬於「選擇」而不是「變強」**，所以算進 g 上限（×1.32 = 1.20 × 1.10）。
- 之後有多種屬性武器時，規則：屬性倍率**只乘一次**（武器有一個屬性），不跟星圖、套裝疊。

### 3.6 經驗與 HR
- 現行 `hrNeed = 20 + 15(HR−1)`（每級線性 → 累計二次，b=2）、`huntExp = 20 + 3·Lv`（輸一半）。這正是研究 §1.2 建議的 b=1.5～2：第一場就升 HR2，HR10 約 18 場、HR12 約 26 場（已驗算，附錄 A4）。
- 時間表算出 14 節後 HR 14（建議案）～16（現行），每節 1 場時 11、3 場時 20（已驗算，附錄 A6）。**不用改**。
- HR 不影響戰鬥數值（§3.2），所以它只是「出席與努力的刻度」，跟 `SPEC` §2.2 刪掉獵人等級榜的理由一致。

### 3.7 字元：收入與價格（以「多久買得起」反推）
```
收入/場    huntCoins = (20 + 6·Lv) × (贏 1／輸 0.5)
收入/節    I = 場數 × 平均每場       ← 取決於學生打到哪一區，不是常數
價格       P = I × 目標節數
```
**發現**（已驗算，附錄 A4、A5、A6）：
- 現行解鎖規則（某星贏一場就開下一星）下，三組學生都在第 3 節進森林、第 6～8 節打到森林★5，之後每場都拿森林的 116～152 字元：14 節累計 **3,100～3,600**，學期末**手上還剩 1,000～1,500 沒處花**（違反 D8）。`SPEC` §3.8 用「20 節 2,500～3,000」估，**低估了**。
- 建議案（某星要贏過 2 種不同魔物才開下一星，§3.9）：每節約 180、14 節累計約 2,500，學期末手上 150～190（約 1 節收入，符合 D8）。

價格（建議案的收入，單位：節）：

| 東西 | 字元 | 要幾節 | 目標 | 判定 |
|---|---|---|---|---|
| 布裝一件 | 30 | 0.2 | ≤1 | ✓ |
| 綠防具一件 | 120 | 0.7 | ≤1 | ✓ |
| 強化灰 +0→+3 | 110 | 0.6 | ≤1.5 | ✓ |
| 強化綠 +0→+3 | 220 | 1.2 | ≤1.5 | ✓ |
| 炎牙刀 | 250 | 1.4 | — | ✓ |
| 改名卡 | 300 | 1.6 | — | ✓ |
| 布裝四件＋全強化 +3 | 560 | 3.1 | 3～4 | ✓ |
| 全身綠 +5 | 3,600 | 20 | 約 2 學期 | 1.4 學期 ✓ |

- 強化費用 `2.5n² + 7.5n + 10`（× 灰 1／綠 2／藍 3）**照用**：每 +1% 攻擊力的花費 10 → 59 字元，遞減報酬已經內建（研究 §4.2，已驗算）。
- 之後新增價格的公式（設計決定）：`價格 = 目標節數 × I_該區`，`I_該區 = 2 × (20 + 6·該區平均 Lv)`；**排水口跟著收入走**，新區域的強化顏色倍率用同一條（紫 4、橙 5、金 6）。

### 3.8 材料與圖紙掉落
- 材料：贏全拿、輸一半最少 1（確定性，照用）。
- 圖紙：每張 30%、保底 K=5（連 5 場沒掉，第 6 場必掉）。單張期望 2.94 場、最壞 6 場；一隻魔物兩張都學到：期望 4.4 場、p95 9 場（已驗算，附錄 A4，DP 精確算）。符合 D9。
- 換參數的對照：p=0.2、K=5 → 單張 3.69、兩張 p95 11；p=0.3、K=3 → 2.53／7（已驗算）。**建議維持 0.3／5**。
- 之後若加「機率材料」，設計值用 p95：`n95 = ⌈ln 0.05 / ln(1−p)⌉`（p=0.3 → 9 場）。

### 3.9 區域與星級解鎖
- 現行：贏某區 ★n 任一隻 → 開 ★n+1；草原 ★5 → 開森林。解析結果：**每一星幾乎都一場就過**（森林★5 慢 2.1 場、其他 ≈1 場，已驗算附錄 A4），所以現有內容第 6～8 節就打完，後面 6～8 節沒有新目標。
- **為什麼現在技巧不太影響進度**：層級（HP_TIER）本來就把各速度的壓力拉平，所以「解鎖速度」主要看出席。這是**刻意的**（不讓慢的孩子落後），但代價是要靠「目標關」（炎牙狼★5）讓快的孩子有挑戰。
- **建議（設計決定）**：`ZONE_CLEAR_NEED = 2`——某一星要打贏 **2 種不同魔物** 才開下一星。效果（已驗算，附錄 A5）：中位學生第 6 節草原★5、第 12 節森林★4、第 14 節森林★5；同時逼孩子換魔物，綠材料與圖紙更平均。`3` 太慢（第 14 節才到森林★2）。

## 4. 一學期的進度時間表

### 4.1 怎麼算
`curves.mjs timeline`：每組 200 位學生（組內速度 ±10%），14 節 × 2 場，鐵匠鋪第 1 節就開，每場依 §2 的勝率擲骰。策略假設：挑「勝率 ≥55% 的最高星級」，同一星優先打還沒贏過、還有圖紙的魔物（願意為圖紙往回打 2 星）；每場前把錢花在「做／換更好顏色 → 武器強化到 +5 → 防具 +3 → +5」，灰色裝備最多強化到 +1（存錢做綠的）。新學期材料歸零、起始 600 字元（教學大樓三堂課）。

1. 先只做 `nw-balance.js` 搬家（數字不變），`curves.mjs` 改成從它 import，跑一次確認輸出跟附錄一樣。
