# 新世界 UI 與美術規範

給之後要新增建築、魔物、武器、畫面的人。照這份做，新東西放進去就會跟其他東西長得一樣。
最後更新：2026-11-04。

---

## 0. 設計評判（改版前，從遊戲設計師與美術設計師的角度看）

### 遊戲設計
| 問題 | 為什麼是問題 | 怎麼改 |
|---|---|---|
| 獵人村是一排按鈕 | 村子應該是「一個地方」，走進去、看到有哪些建築，才有「我在新世界」的感覺；按鈕選單跟網頁沒兩樣 | 垂直俯視的村莊地圖，點哪裡角色就走過去，走到建築門口才打開功能 |
| 還沒開的設施只有斜紋 | 孩子看不出「這裡以後會有什麼」，也沒有期待 | 建築照樣畫出來，整棟變灰、掛鎖鏈與「施工中」牌子，輪廓看得出是鐵匠鋪、商店 |
| 新世界入口只是營地的一顆按鈕 | 傳送門是整個故事的起點，卻沒有儀式感 | 營地裡放一扇像素的門：沒開放＝灰色石門＋鎖鏈；開放＝紫色漩渦 |
| 戰鬥畫面只佔畫面中間一小塊 | 戰鬥是最重要的畫面，卻留了一圈黑邊；魔物看起來很小 | 滿版：場景鋪滿整個視窗，介面疊在上面 |
| 連弩的箭是「一整排同時出現」 | 看起來像霰彈槍，跟「機關槍連發」的設計意圖不一樣；打擊感少一半 | 一支一支依序射出，每支有槍口火花、後座力、命中火花與小傷害數字 |
| 介面資訊平均分配 | 孩子在戰鬥中只需要看：魔物血量、自己血量、題目、紅區。其他都是干擾 | 依「視線順序」排版：上方魔物與倒數 → 中間場景 → 下方題目；次要資訊縮小 |

### 美術
| 問題 | 為什麼是問題 | 怎麼改 |
|---|---|---|
| 場景是像素，介面卻是一般網頁卡片 | 兩種風格打架，像把網頁貼在遊戲上 | 介面也用像素邊框、階梯轉角、硬陰影，字加黑邊 |
| 圓角、漸層、模糊陰影 | 都不是像素語彙 | 全部改成「整數像素」的邊框與陰影（0 模糊） |
| 顏色太多、沒有系統 | 每個畫面自己挑色 | 固定一組調色盤（見 §2），建築、介面共用 |
| 魔物放大 2 倍而角色 1 倍 | 像素密度不一致 | 保留（魔物是 BOSS，故意大），但**介面與地圖一律同一個像素格** |

---

## 1. 像素格（最重要的一條）

- 所有畫面的「1 個像素」大小必須相同：整個畫面選一個整數倍率 `s`，**不能有 1.5 倍、不能補間**。
- 圖一律 `image-rendering: pixelated`。
- 邏輯尺寸（放大前）：

| 東西 | 邏輯大小 | 倍率（桌機／手機） |
|---|---|---|
| 武器圖示 | 28×28 | 5／3 |
| 魔物 | 40×32 | 6／4（戰鬥中放大 2 倍） |
| 角色（戰鬥，背面） | 26×30 | 1（戰鬥場景內） |
| 角色（地圖，四方向走路） | 16×20 | 同地圖 |
| 建築 | 48×48（3×3 格） | 同地圖 |
| 地圖一格 | 16×16 | 4～5／2 |
| 戰鬥場景 | 寬隨視窗、高 96 | 依視窗高度取整數倍 |
| 門（營地） | 40×56 | 3～4 |

## 2. 調色盤

| 用途 | 色碼 |
|---|---|
| 視窗底（深藍紫） | `#1b1738` → `#2a2358` |
| 視窗外框（亮） | `#f0eee8` |
| 視窗外框（暗） | `#0a0714` |
| 金色（重點、選中） | `#e8b64c`／`#ffd98a` |
| 文字 | `#f0eee8`，黑邊 `#000` |
| 灰（未解鎖） | 由原色轉亮度，再壓暗 30% |
| 草地 | `#5fae45` `#68b84c` `#4a9a3a` |
| 土路 | `#c9a66b` `#a88550` |
| 紅區（閃避型） | `#d83a3a` ／ 藍區（防禦型）`#3a7ad8` |
| 紫（新世界、傳送門） | `#4b22a8` `#7b4dff` `#d9ccff` |

稀有度顏色沿用 GDD §12：灰 `#9aa3ad`、綠 `#6aa84f`、藍 `#3f9be0`、紫 `#a06ad8`、橙 `#e0802a`、金 `#e8b64c`。

## 3. 介面元件（`nw-ui.js`，用 class 名稱呼叫）

| class | 用在 | 說明 |
|---|---|---|
| `.px-panel` | 一般視窗 | 深藍紫底、亮外框、階梯轉角 |
| `.px-panel.in` | 視窗裡的小框 | 比外層暗一階，沒有外框光 |
| `.px-btn` | 按鈕 | 平面、下緣厚 4px，按下去往下沉 4px |
| `.px-btn.gold` | 主要動作 | 金色 |
| `.px-bar` ＋ `<i>` | 血條、經驗條 | 外框＋8px 一格的分段；`.hp` 紅、`.ok` 綠、`.xp` 金 |
| `.px-title` | 標題 | 大字、2px 黑邊、金色 |
| `.px-text` | 內文 | 白字、1px 黑邊 |
| `.px-cursor` | 選項前面的 ▶ | 閃爍 |
| `.px-chip` | 小標籤 | 例如「熟悉的」「最先開放」 |

規則：
- 邊框、陰影只用整數像素（`box-shadow: 0 4px 0 …`），**不用 blur**。
- 不用 `border-radius`，轉角用 `clip-path` 做階梯。
- 字一律加黑邊（`text-shadow` 四個方向 1px）。
- 可以點的東西 hover 時要有變化（上移 2px 或亮邊）。

## 4. 村莊、世界地圖與背包

### 村莊（參考《元氣騎士》的大廳）
- **一個畫面看完**：22×15 格的小鎮，依螢幕高度取整數倍率；放不下才跟著角色捲動。不要做成長長的直條。
- **不規則**：建築錯落在中央廣場四周，小路是自然彎曲的（不是方格），有噴泉、路燈、水池、木桶、箱子、花圃、乾草堆。
- **會動**：村民在附近走動，點他會說一句國小生看得懂的話；噴泉冒水、鐵匠鋪冒煙、星圖台閃星、路燈微光、傳送門漩渦。
- **操作**：WASD／方向鍵走路，或點任何地方走過去；點建築會自己走過去再打開、站在門口附近按 Enter 也行（不會走過就觸發）；走進傳送門回舊世界；手機只用點的。
- 建築朝下，門在底邊中央。**不能碰到就觸發**：只能點建築，或站在附近（`REACH`）按 Enter。要新增建築：`pixel.js` 的 `buildingGrid` 加一種、`nw-data.js` 的 `VILLAGE.buildings` 加一列（`x`、`y` 是左上角格子，footprint 3×3）。
- 未開放的建築：整張轉灰、掛鎖鏈與掛鎖，名牌寫「施工中・第 N 段」，**輪廓要看得出是什麼店**。
- 新世界裡沒有「營地」：個人的東西（裝備、造型、道具、材料、圖紙、任務、圖鑑）全部放進**背包**（B 鍵或右上角按鈕）。

### 委託板（`nw-board.js`）
- **只選委託單**：木頭看板（`PX.wood`）上釘著幾張舊紙（`PX.paper`、`PX.pin`），每張用不規則的 `clip-path` 多邊形裁出破邊、微微歪斜，不要排成整齊方格。
- 一張單子只放：星級、魔物名、**單色墨水風魔物圖**（`PX.ink`，不用彩色）、等級、區域。完成過的蓋「已討伐」章，還沒開放的畫模糊剪影＋鎖。
- **右邊一張大地圖**（`PX.bigMap`，240×180）：魔物各自住在自己的地盤。選單子時地圖放大到那一區，打定位光圈（ping）、畫地盤範圍並釘上圖釘。地圖不是節點、不能點。
- 看板上方分頁：「委託」「目前的房間」。房間列表只列開著的房間；組隊第 3a 段開放前，加入按鈕是灰的。
- 按「狩獵」才建立房間，不是選單子就開。
- 新增魔物：`nw-data.js` 的 `MONSTERS` 加一列、`BIGMAP.areas/spots` 加地盤、`pixel.js` 的 `inkGrid` 確認有輪廓。

### 背包（JRPG 選單）
- **左邊人物卡**：最上面名字，下面是稱號按鈕（徽章＋稱號，點了開編輯器）；中間是角色，左右各排裝備格（左：頭盔／盔甲／護腳，右：武器／護手），格子下面寫部位名；沒裝備的格子是暗色的「＋」。
- **右邊**：上面分頁（裝備背包、道具、材料、圖紙、任務、圖鑑），內容是 4 欄的裝備格子；用 `px-panel` 與 `px-btn`，選中的分頁是金色。
- **稱號編輯器**（`#nw-title`）：上方預覽徽章與稱號，三個詞條格，下面三組詞條；沒解鎖的灰階加鎖，並直接寫條件。
- **稱號徽章一律用 SVG 像素格畫**（`PX.badge(tier, 倍率)`，`shape-rendering: crispEdges`），不用 emoji。
- 新的個人資料（例如寵物）加一個分頁；不要再另外做一個全螢幕頁面。

## 5. 戰鬥畫面

- **滿版**：場景鋪滿視窗，介面疊在場景上，不留黑邊。
- 場景高度固定 96 邏輯像素，倍率 = 視窗可用高度 ÷ 96（取整），寬度依視窗補滿。
- 版面（由上到下）：魔物名牌與血條（上中）→ 倒數條（名牌下）→ 場景 → 底部操作視窗（題目、輸入、血條、武器能量）。
- 每個攻擊／動作都要有：動畫、聲音替代（畫面震動或閃白）、數字回饋。
- **三線戰鬥**（唯一的戰鬥操作；舊的打字「閃／防」在 v3.9.1 已刪除）：地面分左、中、右三線（`LANE_C`），角色站在其中一線（腳下金色底線）。
  - 操作只有 **左 Ctrl＝往左一線、右 Ctrl＝往右一線、Alt（左右皆可）＝舉盾**（按一下 1.5 秒、按住一直舉，沒有冷卻）。不用方向鍵、數字鍵（會被注音輸入法吃掉或搶用），也不處理手機。
  - 魔物出招：先蓄力（`nwb-cast` 的條），最後 2～3 秒（依難度層級 `LANE_W`）有線變紅或整排變藍；招式有單線、夾擊（兩線紅、一條安全）、橫掃（依序）、假動作，★1～★2 只有單線與夾擊；藍色「重壓」一定要舉盾。
  - 站在紅線上舉盾只擋一半傷害；站在安全線不受傷；重壓時舉盾完全擋住。
  - 輸入框上方的「姿態條」改成提示：「✅ 你這一線安全」「⚠ 你這一線危險！用 Ctrl 換線」「🛡 整排都危險！按 Alt 舉盾」，右邊寫出手倒數與盾剩幾秒。
- 題目一律以國字判定；注音只能當提示小字，不能要求打注音符號。
- 連弩：一支一支依序射出（約 0.055 秒一支）；每支有槍口火花、後座力、命中火花、小傷害數字。

## 6. 動畫規則

- 待機：上下 1 像素的呼吸，週期 0.8 秒。
- 受擊：閃白 0.15 秒（魔物）／閃爍 0.4 秒（玩家）。
- 重要事件用大字標語（詠唱、完美閃避），0.9 秒內淡出。
- 尊重「減少動態效果」：地圖的背景動畫可以關，戰鬥回饋不關。

## 7. 新增東西的檢查表

1. 邏輯尺寸、倍率符合 §1。
2. 只用 §2 的顏色（可以用 `lt()`／`dk()` 取亮暗）。
3. 要有輪廓（`outline`），深色底上的深色角色用亮輪廓。
4. 未解鎖版本＝轉灰＋鎖，不要另外畫。
5. 給學生看的字用國小生看得懂的白話（GDD §2.3）。
6. 把新東西補進預告頁（`NW_*` 清單）與 `CHANGELOG.md`。
