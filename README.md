## 上線前你只要做一件事

**在 Firebase 主控台加上安全規則，否則整個遊戲不能用。**

1. 打開 <https://console.firebase.google.com/> → 選 `school-4c9bf` 專案
2. 左邊選 **Firestore Database** → 上方分頁 **規則**
3. 把 `firestore-rules.txt` 的內容整份貼上去取代原本的 → 按 **發布**

沒做這步的話，學生會看到紅字「Firestore 權限不足」，只能用「自由練習」，成績不會存。
（那份規則檔裡也保留了舊站要用的 `competition` / `scores`，直接整份取代就好，舊站不會壞。）

## 一堂課怎麼跑

1. 學生各自打開網址 → 選班級、填座號姓名 → 進入**營地**，在這裡把武器和品質挑好
   （座號一填好，登入畫面就會把這個座號的歷史成績撈出來：階級徽章、歷史最高傷害、
   挑戰次數，姓名也會自動帶出來。第一次來當然什麼都沒有，那塊就不會出現。）
   **史上第一次登入**會先進一段 30 秒左右的新手教學：簡介介面、
   讓學生各試打法杖／弓箭／匕首兩題，背後順便量出這位學生的手速，
   拿來當動態難度的起點（詳見〈難度怎麼調〉）。教完才進營地，以後不會再出現。
2. 老師點右上角 **⚙️ 教師** → 密碼 `teacher` → **比賽控制** → 按 **開始比賽**
3. 全班同時開始倒數（實測多數班級設 120 秒，兩分鐘一輪方便一堂課跑好幾輪；
   要設多長都可以，**全班 BOSS 的血量會自動依這個時間縮放**，見〈難度怎麼調〉）
4. 時間到 → 先播「全班總傷害討伐怪獸」的動畫 → 再進結算畫面
   （左邊是自己的成績＋這場評價 S/A/B/C/D，右邊是班內前 10 與跨班排行）
5. 老師到 **成績管理** → 匯出 Excel（含個人成績表 + 班級總表兩個工作表）
6. 下一節課前按 **回到營地** 清除開戰狀態（不會刪成績）

> 電腦教室常常是輪流用的：營地右上角有 **換人／回登入**，
> 按下去會回到登入畫面並清掉目前的身分，下一位同學直接填自己的座號就好。

> 學生成績用「**班級 + 座號**」當識別（文件 ID 例如 `五年級3班_12號`），
> 所以換一台電腦、清快取都接得回同一筆紀錄，同班同名也不會再互相蓋掉。
> **座號是必填的**；姓名只是顯示用，第二次登入會自動帶出來，
> 學生要是改了名字，就以新填的那個為準覆蓋回紀錄。
>
> 換句話說，換班或重新編座號等於換一個人。學年中途調座位的話，
> 請先把 Excel 匯出備份。

## 三把武器

一般攻擊三把武器**共用同一份題庫**，難度由學生自己選的品質決定。
同樣速度下的傷害是 **法杖 > 匕首 > 弓箭**，但各自的爆發點不同：

| | 一般攻擊 | 爆發 |
|---|---|---|
| 法杖 | 傷害最高（每字 ×2.2），每個正確標點再 +3 | **詠唱**：每 5 題出現一次標點特別多的長句，全部打對傷害 ×3 |
| 匕首 | 傷害固定（每字 ×2.0），不看速度 | **連環斬**：每 5 題出現一次，一口氣串幾個詞組，打越快傷害越高（最高 ×3.2） |
| 弓箭 | 傷害隨正確率直線上升，最穩定 | **神射手**：打對累積爆擊條，集滿後連續 3 題傷害 ×2，但期間**看不到自己打錯** |

**連環斬最多串到 12 個字。** 普通、精良是兩字詞，三個串起來剛好六個字；
史詩三～四字，串到三個大約十二字；傳奇一句就十四字，所以通常只出一句
——不會再出現三句黏成四十幾字、輸入框根本看不完的題目。
要調就改 `index.html` 裡 `BALANCE.flurry.maxChars`（所有數值都集中在 `BALANCE`
這個物件，規格書在 `docs/BALANCE.md`）。

**連續全對會疊連擊加成**（每連擊 +6%，最多 +90%），傷害數字下面會多跳一個
小一號的金色「追加 +N」；打錯一次連擊就斷，標籤閃紅一下。

## 四階武器品質

品質是學生自己在營地挑的，決定題目難度與傷害倍率：

| 品質 | 倍率 | 題目 | 鍵盤輔助 | 解鎖條件 |
|---|---|---|---|---|
| 普通 | 1.5× | 最常用的簡單兩字詞（媽媽、天空、跑步） | **有** | 一開始就有 |
| 精良 | 2.0× | 一般兩字詞（觀察、磁鐵、謙虛） | 無 | 歷史最高到達 **LV 4** |
| 史詩 | 2.9× | 三～四字詞組與成語 | 無 | 歷史最高到達 **LV 8** |
| 傳奇 | 4.2× | 五～十四字的句子 | 無 | 歷史最高到達 **LV 12** |

品質倍率只決定經驗值權重、班級總傷害貢獻跟戰績分加成——**不是怪物變不變軟**。
血量是依玩家「目前等級」即時算出來的（見〈難度怎麼調〉），所以不管選哪個品質，
打倒一隻怪大概都是那幾下；選高品質純粹是「升級比較快、每下比較重」，
不會有人為了多殺幾隻而一直賴在普通。

### 難度鎖

**高一階要先打到一定等級才選得到。** 學生第一次進來只有「普通」可以用，
營地裡其他三格是灰的、虛線框、標著還差幾級。判斷的依據是**歷史最高到達等級**
（`bestLevel`，局內等級見〈動態難度與局內等級〉），跟著班級＋座號存，換電腦也接得回來。

- 升級跨過門檻的當下就會跳出金色橫幅「解鎖新難度：精良」，
  同一場同一階只跳一次，四秒後自己收掉，不會蓋到怪獸血條。
- 戰鬥中不能換品質，所以解鎖的那一階要**回營地**才選得到。
- 學生挑過的那一階會被記住：本來選傳奇但紀錄被清空而退回普通，
  等他重新打到 LV 12，系統會自動幫他選回傳奇。
- 要調鬆緊改 `index.html` 裡 `BALANCE.unlockLevel`。

**普通這一階會在畫面下方長出一整排注音鍵盤**，當下該打的那個字要按哪幾個鍵
就亮成金色（含聲調鍵），旁邊還會把那個字和它的注音放大顯示。
給還在低頭找鍵位的孩子用，找到鍵位以後就可以自己往上跳一階。

**普通不會出現法杖的「詠唱」**，那是十幾到三十字、標點又多的長句，
對還在找鍵位的孩子太硬了。選普通就從頭到尾都是兩字詞，
代價是這一階沒有 ×3 的爆發可以吃。

倍率的設計：精良／史詩／傳奇就是舊版的普通／精良／傳奇，數字一個都沒動；
普通是補在最下面的一階，倍率低一點，但血量公式已經把品質倍率抵銷掉了
（見下一節），所以四階的「手感」其實很接近，差別在升級快慢跟每下傷害。

設計上的用意：匕首的速度加成集中在連環斬，學生沒辦法全程維持高速；
弓箭的神射手把即時上色關掉，變成「盲打」的緊張時刻。

**武器在營地選定後，戰鬥中不能更換**，所以出發前要想清楚。
學生操作：`Enter` 送出攻擊、`Esc` 跳過此題（連擊歸零）。

## 難度怎麼調

**血量不是寫死的，是算出來的。** 每隻怪的血量由「打倒這一隻需要幾個
正確字」反推，這個數字隨玩家**目前等級**平滑成長：LV1 大約 4 個字
（普通兩字詞剛好 2 下），LV3 大約 6 個字（3 下），愈往後愈長但有攻擊力
同步成長在抵銷，所以「要打幾下」整場都穩定在 2～3 下左右，不會有人卡死
在同一隻怪。完整公式與理由在 **`docs/BALANCE.md`**。

### 局內等級與動態難度（DDA）

- **局內等級**：每場從 LV1 重來，打字、全對、擊倒都給經驗，升級 +4% 攻擊力。
  畫面上方有一條經驗條，怪物也會依等級換區域出現（史萊姆在 LV1-5、
  哥布林在 LV6-10……每區最後一級是王級，每擊倒 5 隻出一次菁英）。
- **動態難度（DDA）**：每位學生有自己的一條血量倍率，每場打完依「這場擊倒
  幾隻」自動調整——目標是每場推倒 4～8 隻。**史上第一次登入**不是用預設值
  猜，是先跑一段新手教學（試打三把武器各兩題）量出真實手速，拿這個數字
  當起點，之後每場再繼續微調。
- 教師控制台的**難度係數**滑桿還留著，是「全班統一再乘一次」，正常情況
  放 1.0 就好——個人難度已經會自動校準，不用像舊版那樣全班共用一個係數。

### 全班 BOSS

個人小怪的血量是算出來的，**全班 BOSS 的血量會依老師設定的比賽時間縮放**
（基準是 120 秒），所以不管一堂課打 2 分鐘還是 10 分鐘，全班合力大概都能
推倒 3～5 隻。要調鬆緊改 `index.html` 裡 `BOSSES` 的 `hp`（這是 120 秒基準值）。

### 想確認數字沒有跑偏

```
node tools/balance-sim.mjs
```

這支工具直接讀 `index.html` 裡的 `BALANCE` 物件（不是另外存一份數字），
印出血量表、DDA 收斂模擬、不同打字速度的擊倒數對照表。改完 `BALANCE`
想確認有沒有改壞，跑一下這支比自己用試算表算快多了。

## 勇者階級（獎章）

結算畫面上的徽章看的是**戰績分**（`每分鐘正確字數 × 品質加成 × 正確率`），
**不是總傷害**——總傷害同時受打字速度、品質倍率、場次長度影響，2026-09
改版前用總傷害訂門檻，實測下來 53% 的學生整學期都卡在見習生，换算成
「每分鐘打幾個字」才是真正跨品質、跨場次長度都能公平比較的數字：

| 階級 | 門檻（戰績分） |
|---|---|
| 見習生 | 0 |
| 冒險者 | 4 |
| 銅級勇者 | 7 |
| 銀級勇者 | 11 |
| 金級勇者 | 16 |
| 傳說勇者 | 23 |

門檻是拿 2026-09 實測的 139 筆紀錄校準的，要再鬆或再緊改 `index.html` 裡
`BALANCE.rank.thresholds`。（登入畫面也用同一套階級顯示歷史最高分的徽章。）

結算畫面同時有一個**單場評價 S / A / B / C / D**，看的是這場的擊倒數、
正確率、最高連擊、到達等級、有沒有比上一場進步，每個等第配一句針對弱項
的建議。門檻在 `BALANCE.grade`。

## 換美術不用改程式

`assets/` 裡的 ASCII 圖都是純文字檔，用記事本改完存檔、重新整理網頁就換掉了。
怪獸的名字、顏色寫在 `assets/manifest.json`（小怪的 `hp` 這欄 2026-09 改版後
已經不影響血量，血量是算出來的，見〈難度怎麼調〉；BOSS 的 `hp` 還有效）。
細節看 `assets/README.txt`。

**兩個注意事項：**

1. 一定要用等寬對齊，全形字（中文、全形符號）寬度是半形的兩倍，會讓圖歪掉。
2. **直接雙擊 `index.html` 用 `file://` 開啟時，`assets/` 不會生效** —— 瀏覽器基於安全考量
   禁止本機網頁讀取其他檔案。這種情況遊戲會自動退回內建美術，不會壞掉。
   要讓 assets 生效，網頁必須透過 http 提供（放上 GitHub Pages 就是）。

改壞了想復原：把整個 `assets` 資料夾刪掉即可，遊戲會用內建的那份。

**BOSS 的圖不是手打的**，是先用程式畫剪影再轉成 ASCII。
想改造型的話改剪影比一格一格打字容易很多，工具和說明放在 `tools/`。

## 注音怎麼處理的

**沒有用注音字體**，而是逐字內嵌注音資料，用 HTML 排版成課本的樣子（注音直排在字的右側、輕聲點在最上方、二三四聲標在右下）。

這樣做的原因：注音字體是「一個字碼對一個字形」，`行`、`重`、`長`、`得` 這些破音字它只會有一個讀音，而且注音藏在字體檔裡，**你看不到也改不了**。改用內嵌資料之後，每個注音都是可以看見、可以修的文字。

### 校對（請務必做一次）

教師控制台 → **🔍 注音校對台**

- 列出全部題庫每一個字的注音，**破音字自動標紅框**
- 這個畫面是**唯讀**的，要改注音請回去編輯 `assets/banks/*.json`
- **匯出校對表** 會產生 Excel，破音字那欄標「★ 請確認」，可以印出來離線核

注音是依教育部《一字多音審訂表》建的，但我不敢保證 100% 正確 —— 尤其下面這些請你優先看：

| 字 | 目前用了哪些讀音 | 說明 |
|---|---|---|
| 一 | ㄧˋ / ㄧˊ | 變調。課本標變調，但有些版本標本調 ㄧ |
| 不 | ㄅㄨˋ / ㄅㄨˊ | 同上，接四聲時變 ㄅㄨˊ |
| 重 | ㄓㄨㄥˋ（重要）/ ㄔㄨㄥˊ（重新） | |
| 得 | ˙ㄉㄜ（記得）/ ㄉㄜˊ（贏得） | |
| 長 | ㄔㄤˊ（又細又長）/ ㄓㄤˇ（長輩） | |
| 地 | ㄉㄧˋ（地上）/ ˙ㄉㄜ（輕輕地） | |
| 都 | ㄉㄡ | 「都能進步」的都，不是 ㄉㄨ |
| 種 | ㄓㄨㄥˋ | 「種菜」是動詞 |
| 媽/爸/弟/姐/哥/謝 | 疊詞第二字輕聲 | 媽媽 ㄇㄚ+˙ㄇㄚ，這是正常的 |

## 題庫

題目放在 `assets/banks/` 的 **5 個 JSON 檔**，用記事本或 VS Code 直接編輯，
存檔後重新整理網頁就生效。**教師控制台不提供題庫編輯**，外部檔案是唯一來源。

```
common_normal.json    一般 · 普通   最常用的兩字詞（103 題）┐
common_fine.json      一般 · 精良   一般兩字詞（90 題）     ├ 三把武器共用
common_epic.json      一般 · 史詩   詞組與成語（140 題）    │
common_legend.json    一般 · 傳奇   句子（77 題）           ┘
special_staff.json    法杖「詠唱」  標點很多的長句（68 題）
```

| 池 | 字數 | 內容 |
|---|---|---|
| 普通 | 2 字 | 媽媽、天空、跑步、水果、謝謝…… |
| 精良 | 2 字 | 觀察、磁鐵、謙虛、隧道、古蹟…… |
| 史詩 | 3～4 字 | 顯微鏡、資源回收、持之以恆、飲水思源…… |
| 傳奇 | 5～14 字 | 種子發芽需要空氣水分與陽光 |
| 詠唱 | 13～31 字 | 做實驗要記三件事：先假設、再動手、最後把結果寫下來。 |

普通和精良都是兩個字，**分野不在長度而在「字有多常見」**：普通全是每天在用的詞，
精良才開始出現課本上的詞。四池的詞完全不重複（有程式檢查過）。

弓箭的神射手模式和匕首的連環斬都用共用題庫（連環斬是把三個詞組串起來），
所以不需要額外題庫。共 478 題，全部對準**國小中高年級（三～六年級）**：
自然觀察、環境保育、品格、社會人文、閱讀與學習方法，加上中高年級常見成語。

格式：

```json
{ "題目": [
    { "t": "小狗在公園裡跑步。",
      "z": "ㄒㄧㄠˇ ㄍㄡˇ ㄗㄞˋ ㄍㄨㄥ ㄩㄢˊ ㄌㄧˇ ㄆㄠˇ ㄅㄨˋ -" } ] }
```

`t` 是題目，`z` 是逐字注音、空白分隔，**標點符號的位置寫 `-` 佔位**。
最容易錯的是 `z` 的數量必須和 `t` 的字數完全一樣——數量不符的題目會被跳過，
並在瀏覽器主控台留下警告。細節看 `assets/banks/README.txt`。

**只有 `special_staff.json` 會出現標點符號**（，。、：；！？「」『』），其他四池一律不放。
**破折號（——）已經全部拿掉了**：它在等寬字型下佔兩格、學生也不好打，
原本那 7 題已刪除。要加新題目時也請避開破折號與連字號。
這是刻意的：標點是法杖的專屬特色。

## 兩種題目模式

教師控制台可切換：

- **中文模式**（預設）：題目顯示中文，注音標在右側輔助，學生用注音輸入法打中文
- **注音模式**：題目直接顯示注音符號，學生敲注音鍵位不選字 — 適合剛學打字的中年級

同一套題庫兩種模式共用，切換即生效。

## 已知限制

- **全班同步開始靠各台電腦的時鐘**。校內電腦通常有對時所以沒問題；若某台時間差很多，那台的倒數會不準（已經做了夾限，不會出現負數或超長時間）。
- **防作弊只做到基本程度**：擋貼上、擋超打。學生若會開瀏覽器主控台仍可改分數。要更嚴格需要伺服器端驗證，超出單檔網頁的範圍。
- **長題會自動縮字**：題目和輸入框的字級都跟著題目長度縮（輸入框 38→18px），
  所以三十字的詠唱句打到最後，開頭也還看得到，不會被推出框外。
- **匕首的揮砍是握把不動、刀刃往下劈**。第一人稱武器的旋轉支點會即時
  量成「舞台下緣」，也就是手的位置；不設支點的話會繞著圖的正中央轉，
  看起來像拿劍柄在砍人。
- **注音組字中不判定**：中文一個字要按好幾個鍵（小＝ㄒㄧㄠˇ再選字），
  組字途中輸入框裡是還沒選字的注音。遊戲會等 `compositionend`
  才判定，所以不會把第一個字當成「已經打過」標成紅字，
  注音鍵盤也不會提早跳到下一個字。組字中的 Enter／Esc 也留給輸入法用。
- **成績以「本場」為準**，同一輪只會留最後一次；另外會記歷史最高
  （`bestDamage` / `bestWpm` / `bestKills` / `bestLevel` / `bestScore` /
  `bestCombo` / `plays`），登入畫面顯示的就是這幾個。
- **2026-09 改版把傷害數字放大了 8 倍**（`BALANCE.dmgScale`），舊紀錄的
  `bestDamage` 跟這之後的紀錄不能直接比大小，只拿來跟自己比。排名跟徽章
  改用戰績分（見〈勇者階級〉），不受這次調整影響。舊紀錄沒有 `bestLevel`
  欄位時，難度鎖會用 `bestKills × 2` 粗略換算，不會讓老學生一夕被打回原形。
- **「先自己練習」只更新個人歷史最高**，不會寫進 `damage`，
  所以練習分數不會混進班內排行、也不會加到全班總傷害。
  練習的結算畫面也**不顯示班內排行與跨班排行**，只留自己的成績卡。
  （全班討伐 BOSS 的動畫還是會播，那是全班共用的怪。不想播的話跟我說。）
- 歷史成績在瀏覽器另外存一份，**離線也看得到、練習也照樣累積**；
  連線恢復後會跟雲端那份取大的合併。
- Firestore 免費額度是每天 5 萬次讀取。遊戲進行中**不訂閱**排行榜（只在結算時讀一次），一堂課約幾百次讀取，一天跑十個班綽綽有餘。
