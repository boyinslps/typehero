# 打字勇者 · 全班討伐戰

`game.html` ＋ `assets/` — 用瀏覽器打開就能玩，不需安裝任何東西。

```
typing-hero/
├── game.html             遊戲本體（含 163 題注音題庫）
├── assets/               美術素材（ASCII，可自由替換）
│   ├── README.txt        怎麼改的說明
│   ├── manifest.json     怪獸名稱／血量／顏色的總表
│   ├── monsters/         七隻怪獸
│   ├── weapons/          三把武器的第一人稱模型
│   └── fx/               攻擊特效，每把武器三組輪播
├── firestore-rules.txt   要貼進 Firebase 主控台的安全規則
└── README.md             這份說明
```

原本的純打字站 `網站製作/index (2).html` 完全沒有更動，兩個可以並存。

## 上線前你只要做一件事

**在 Firebase 主控台加上安全規則，否則整個遊戲不能用。**

1. 打開 <https://console.firebase.google.com/> → 選 `school-4c9bf` 專案
2. 左邊選 **Firestore Database** → 上方分頁 **規則**
3. 把 `firestore-rules.txt` 的內容整份貼上去取代原本的 → 按 **發布**

沒做這步的話，學生會看到紅字「Firestore 權限不足」，只能用「自由練習」，成績不會存。
（那份規則檔裡也保留了舊站要用的 `competition` / `scores`，直接整份取代就好，舊站不會壞。）

## 一堂課怎麼跑

1. 學生各自打開網址 → 選班級、填座號姓名 → 進入**營地**，在這裡把武器和品質挑好
2. 老師點右上角 **⚙️ 教師** → 密碼 `teacher` → **比賽控制** → 按 **開始比賽**
3. 全班同時開始倒數（預設 600 秒）
4. 時間到 → 先播「全班總傷害討伐怪獸」的動畫 → 再進結算畫面
   （左邊是自己的成績，右邊是班內前 10 與跨班排行）
5. 老師到 **成績管理** → 匯出 Excel（含個人成績表 + 班級總表兩個工作表）
6. 下一節課前按 **回到營地** 清除開戰狀態（不會刪成績）

> 學生成績用「班級 + 姓名」當識別，所以換一台電腦、清快取都接得回同一筆紀錄。
> 同班同名會撞在一起，這種情況請讓其中一位在姓名後面加座號。

## 三把武器

| | 題型 | 機制 |
|---|---|---|
| 🔮 法杖 | 短句，含標點符號 | 傷害穩定。每打對一個標點額外 **+150** |
| 🏹 弓箭 | 生難字、形近字、成語 | 傷害 × 正確率的**平方**；全對「一箭穿心」**雙倍** |
| 🗡️ 匕首 | 短詞，好打 | 連續打對一題連擊 +1，傷害 ×(1+連擊×0.1)；打錯**歸零** |

品質倍率：普通 1.0× / 精良 1.6× / 傳奇 2.6×。
連擊：打出完美攻擊就累加，打錯全部歸零。只有匕首能把連擊換成傷害，所以選匕首的人要特別穩。

**武器在營地選定後，戰鬥中不能更換**，所以出發前要想清楚。
學生操作：`Enter` 送出攻擊、`Esc` 跳過此題（連擊歸零）。

## 難度怎麼調

怪獸有 7 隻，血量遞增：史萊姆 3萬 → 大蝙蝠 6萬 → 哥布林戰士 12萬 → 骷髏騎士 20萬 → 石魔像 32萬 → 火焰惡龍 50萬 → 混沌魔王 80萬（累計 203 萬）。

用模擬跑過 28 人班級 × 10 分鐘的結果：

| 班級程度 | 全班總傷害 | 擊倒 | 建議難度係數 |
|---|---|---|---|
| 初學 8 WPM | 約 34 萬 | 3 隻 | 0.5× |
| 四年級平均 14 WPM | 約 68 萬 | 4 隻 | 1.0×（預設） |
| 五年級平均 20 WPM | 約 99 萬 | 5 隻 | 1.4× |
| 熟練班級 28 WPM | 約 157 萬 | 6 隻 | 2.2× |

第一次帶班就用預設 1.0×，跑完看擊倒幾隻，再用**難度係數**滑桿校準。目標大概抓「一堂課推倒 4 隻」，學生比較有成就感又清不完。

## 換美術不用改程式

`assets/` 裡的 ASCII 圖都是純文字檔，用記事本改完存檔、重新整理網頁就換掉了。
怪獸的名字、血量、顏色寫在 `assets/manifest.json`。細節看 `assets/README.txt`。

**兩個注意事項：**

1. 一定要用等寬對齊，全形字（中文、全形符號）寬度是半形的兩倍，會讓圖歪掉。
2. **直接雙擊 `game.html` 用 `file://` 開啟時，`assets/` 不會生效** —— 瀏覽器基於安全考量
   禁止本機網頁讀取其他檔案。這種情況遊戲會自動退回內建美術，不會壞掉。
   要讓 assets 生效，網頁必須透過 http 提供（放上 GitHub Pages 就是）。

改壞了想復原：把整個 `assets` 資料夾刪掉即可，遊戲會用內建的那份。

## 注音怎麼處理的

**沒有用注音字體**，而是逐字內嵌注音資料，用 HTML 排版成課本的樣子（注音直排在字的右側、輕聲點在最上方、二三四聲標在右下）。

這樣做的原因：注音字體是「一個字碼對一個字形」，`行`、`重`、`長`、`得` 這些破音字它只會有一個讀音，而且注音藏在字體檔裡，**你看不到也改不了**。改用內嵌資料之後，每個注音都是可以看見、可以修的文字。

### 校對（請務必做一次）

教師控制台 → **🔍 注音校對台**

- 列出全部題庫 1139 個字的注音，**破音字自動標紅框**（目前 12 個）
- 點任何一格就能直接改，按下方儲存會存回 Firestore，全班下次載入生效
- **匯出校對表** 會產生 Excel，破音字那欄標「★ 請確認」，可以印出來離線核

注音是依教育部《一字多音審訂表》建的，但我不敢保證 100% 正確 —— 尤其下面這些請你優先看：

| 字 | 目前用了哪些讀音 | 說明 |
|---|---|---|
| 一 | ㄧˋ / ㄧˊ | 變調。課本標變調，但有些版本標本調 ㄧ |
| 不 | ㄅㄨˋ / ㄅㄨˊ | 同上，接四聲時變 ㄅㄨˊ |
| 重 | ㄓㄨㄥˋ（重要）/ ㄔㄨㄥˊ（重新） | |
| 得 | ˙ㄉㄜ（記得）/ ㄉㄜˊ（贏得） | |
| 長 | ㄔㄤˊ（又細又長）/ ㄓㄤˇ（長輩） | |
| 地 | ㄉㄧˋ（地上）/ ˙ㄉㄜ（輕輕地） | |
| 都 | ㄉㄡ | 「都能進步」的都，不是 ㄉㄨ |
| 種 | ㄓㄨㄥˋ | 「種菜」是動詞 |
| 媽/爸/弟/姐/哥/謝 | 疊詞第二字輕聲 | 媽媽 ㄇㄚ+˙ㄇㄚ，這是正常的 |

## 題庫

9 池（3 武器 × 3 品質），共 **163 題**，全部用國小詞彙。
教師控制台 → **📚 題庫編輯** 可以整池改寫或還原成內建預設。

格式是每行一題：

```
小狗在公園裡跑步。|ㄒㄧㄠˇ ㄍㄡˇ ㄗㄞˋ ㄍㄨㄥ ㄩㄢˊ ㄌㄧˇ ㄆㄠˇ ㄅㄨˋ -
```

`|` 後面接逐字注音、空白分隔，**標點符號用 `-` 佔位**。字數對不上會擋下來不給存，不會默默壞掉。

## 兩種題目模式

教師控制台可切換：

- **中文模式**（預設）：題目顯示中文，注音標在右側輔助，學生用注音輸入法打中文
- **注音模式**：題目直接顯示注音符號，學生敲注音鍵位不選字 — 適合剛學打字的中年級

同一套題庫兩種模式共用，切換即生效。

## 已知限制

- **全班同步開始靠各台電腦的時鐘**。校內電腦通常有對時所以沒問題；若某台時間差很多，那台的倒數會不準（已經做了夾限，不會出現負數或超長時間）。
- **防作弊只做到基本程度**：擋貼上、擋超打。學生若會開瀏覽器主控台仍可改分數。要更嚴格需要伺服器端驗證，超出單檔網頁的範圍。
- **成績以「本場」為準**，同一輪只會留最後一次；另外會記一個 `bestDamage` 歷史最高。
- Firestore 免費額度是每天 5 萬次讀取。遊戲進行中**不訂閱**排行榜（只在結算時讀一次），一堂課約幾百次讀取，一天跑十個班綽綽有餘。
