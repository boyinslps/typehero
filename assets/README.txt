打字勇者 · 美術素材
================================================================

這個資料夾裡的 ASCII 圖都可以直接用記事本編輯，存檔後重新整理網頁就會換掉。
不需要動 index.html。

  manifest.json   總表：怪獸的名字、血量、顏色，以及各檔案的對應
  personal/       學生自己打的小怪（檔名的數字＝出場順序）
  bosses/         時間到才登場、吃全班總傷害的大 BOSS
  weapons/        三把武器的第一人稱模型（畫面左下角那個）
  fx/             攻擊特效，每把武器三組會輪流播放

── 編輯注意事項 ────────────────────────────────────────────────

1. 一定要用「等寬字型」對齊（記事本預設就是）。
   全形字（中文、全形符號）寬度是半形的兩倍，會讓圖歪掉，盡量只用半形。

2. 存檔編碼請選 UTF-8。

3. 怪獸建議不要超過 62 個字元寬，太寬在小螢幕會被裁掉。
   越後面的怪獸畫大一點，看起來才會越強。

4. 檔案開頭和結尾的空行會自動去掉，中間的空行會保留。

5. manifest.json 裡 personal（學生打的小怪）的 hp 從 v2.0 改版後
   已經不影響血量了——血量改成依玩家「目前等級」即時算出來的，
   公式與理由在 docs/BALANCE.md 第 3 節。personal 的 hp 欄位純備查，
   不用管它。bosses（全班討伐的大 BOSS）的 hp 還是有效，是「一場
   120 秒」的基準值，教師控制台設的比賽時間會再等比例縮放這個數字，
   教師控制台的難度滑桿也會再乘上去。

6. 怪物出現在哪個等級不是這份檔案決定的，是 index.html 裡的 ZONES
   （史萊姆、大蝙蝠在 LV1-5，哥布林、食人樹妖在 LV6-10……依此類推，
   詳見 docs/BALANCE.md 第 6 節）。personal 陣列裡每一項有一個內部
   key（slime／bat／goblin…），ZONES 認的是這個 key 不是 name，
   所以在這裡改名字、換圖完全不會影響怪物出現的等級區間，放心改。

── 如果改壞了 ──────────────────────────────────────────────────

index.html 裡面有一份內建的美術當後備。
只要 assets 資料夾讀不到（檔案刪掉、JSON 格式錯誤、或直接用
file:// 開啟網頁），遊戲會自動用內建的那份，不會壞掉。
想恢復原狀，把整個 assets 資料夾刪掉即可。

── 為什麼直接雙擊 index.html 會用內建美術 ────────────────────────

瀏覽器基於安全考量，禁止 file:// 網頁讀取本機其他檔案。
要讓 assets 生效，網頁必須透過 http 提供，例如放上 GitHub Pages，
或在這個資料夾執行：  python -m http.server
然後開 http://localhost:8000/index.html
