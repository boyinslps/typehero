打字勇者 · 題庫
================================================================

六個 JSON 檔。用記事本或 VS Code 就能改，存檔後重新整理網頁即可
生效，不需要動 index.html。

  index.json              五個題庫檔的對應表

  common_normal.json      一般攻擊 · 普通    2 字     103 題  ┐
  common_fine.json        一般攻擊 · 精良    2 字      90 題  ├ 三把武器
  common_epic.json        一般攻擊 · 史詩    3～4 字  140 題  │ 共用
  common_legend.json      一般攻擊 · 傳奇    5～14 字  77 題  ┘

  special_staff.json      法杖「詠唱」       11～31 字  94 題
                          └ 精良 26 題（11～14 字）
                            史詩 36 題（13～17 字）
                            傳奇 32 題（14～31 字）

  全部 504 題，程度對準國小中高年級（三～六年級）。

  普通和精良都是兩個字，差別在「字有多常見」：
  普通是媽媽、天空、跑步這種每天在用的詞，精良才開始出現
  觀察、蒸發、磁鐵這類課本上的詞。四池的詞不可以重複。

  普通這一階在遊戲裡會多出一排注音鍵盤，該按的鍵會亮起來，
  所以這一池請盡量只放注音單純、孩子唸得出來的詞。

── 一般題庫共用，只有法杖的特殊攻擊分開 ────────────────────────

  平常三把武器都從 common_* 抽題，難度由學生選的品質決定。
  每 5 題會插入一次「特殊攻擊」：
    法杖「詠唱」   從 special_staff.json 抽題
    匕首「連環斬」 把 common_* 的三個詞組串起來，不需要另外的題庫
    弓箭「神射手」 連續 3 題照常從 common_* 抽題
  特殊攻擊全部打對，傷害三倍，畫面會跳出招式名稱。

  common_*       一般詞句，不要放標點符號。
                 破折號（——）與連字號不要用，等寬字型下會佔兩格，
                 學生也不好打，special_staff 裡原本那 7 題已經刪掉了。
  special_staff  帶標點的句子（法杖是唯一會出標點的武器），依品質分三階。

── 詠唱題的三階：標點一階一階教 ────────────────────────────────

  法杖的詠唱題不是一次把標點全上，而是跟著武器品質一階一階加。
  每一題用「階」這個欄位決定它出現在哪一階：

    "階": "精良"   只出逗號，句子最短（11～14 字）
    "階": "史詩"   才加句號、問號、驚嘆號、頓號（13～17 字）
    "階": "傳奇"   才出上下引號「」與分號冒號，句子最長（14～31 字）

  普通階不會出詠唱題（還在找鍵位的孩子一個標點都不用打）。

  「階」可以不填：留空或填錯的時候，程式會依這一題的標點種類與
  長度自己判斷（有「」；：或超過 20 字就算傳奇；只有逗號又不超過
  16 字就算精良；其餘算史詩），所以只加題目、不填階也不會壞。
  填錯字（例如寫成「困難」）會在瀏覽器主控台留下警告。

  加題目的時候請順手對一下那一階的標點範圍——
  在精良那一階放一句有句號的，學生就會提早遇到還沒教的標點。

── 格式 ────────────────────────────────────────────────────────

  {
    "題目": [
      { "t": "小狗在公園裡跑步。",
        "z": "ㄒㄧㄠˇ ㄍㄡˇ ㄗㄞˋ ㄍㄨㄥ ㄩㄢˊ ㄌㄧˇ ㄆㄠˇ ㄅㄨˋ -" }
    ]
  }

  t  題目本身
  z  逐字注音，用空白分隔。標點符號的位置寫 - 佔位。
  階 只有 special_staff.json 要填：精良／史詩／傳奇（可留空自動判斷）。

  【最容易錯的地方】z 的數量必須和 t 的字數完全一樣。
  上面的例子 t 有 9 個字（含句號），z 也是 9 個（最後一個是 -）。
  數量對不上，那一題會被跳過，並在瀏覽器主控台留下警告。

── 注音怎麼查 ──────────────────────────────────────────────────

  教師控制台 → 注音校對台，會列出全部題庫的每一個字與注音，
  破音字自動標紅框，也可以匯出 Excel 離線核對。
  那個畫面是唯讀的，改還是要回來改這裡的 JSON。

── 編碼 ────────────────────────────────────────────────────────

  存檔請選 UTF-8。用記事本另存新檔時，編碼那一欄要選 UTF-8。

── 如果改壞了 ──────────────────────────────────────────────────

  index.html 內建一份完整題庫當後備。
  JSON 格式錯誤、檔案刪掉、或直接用 file:// 開啟網頁時，
  遊戲會自動用內建的那份，不會壞掉。
  想全部復原，把 banks 資料夾刪掉即可。
