打字勇者 · 題庫
================================================================

五個 JSON 檔。用記事本或 VS Code 就能改，存檔後重新整理網頁即可
生效，不需要動 game.html。

  index.json              四個題庫檔的對應表

  common_normal.json      一般攻擊 · 普通    2 字      90 題  ┐
  common_fine.json        一般攻擊 · 精良    3～4 字  140 題  ├ 三把武器共用
  common_legend.json      一般攻擊 · 傳奇    5～14 字  77 題  ┘

  special_staff.json      法杖「詠唱」       13～31 字 75 題

  全部 382 題，程度對準國小中高年級（三～六年級）。

── 一般題庫共用，只有法杖的特殊攻擊分開 ────────────────────────

  平常三把武器都從 common_* 抽題，難度由學生選的品質決定。
  每 5 題會插入一次「特殊攻擊」：
    法杖「詠唱」   從 special_staff.json 抽題
    匕首「連環斬」 把 common_* 的三個詞組串起來，不需要另外的題庫
    弓箭「神射手」 連續 3 題照常從 common_* 抽題
  特殊攻擊全部打對，傷害三倍，畫面會跳出招式名稱。

  common_*       一般詞句，不要放標點符號。
  special_staff  標點特別多的長句（法杖是唯一會出標點的武器）。

── 格式 ────────────────────────────────────────────────────────

  {
    "題目": [
      { "t": "小狗在公園裡跑步。",
        "z": "ㄒㄧㄠˇ ㄍㄡˇ ㄗㄞˋ ㄍㄨㄥ ㄩㄢˊ ㄌㄧˇ ㄆㄠˇ ㄅㄨˋ -" }
    ]
  }

  t  題目本身
  z  逐字注音，用空白分隔。標點符號的位置寫 - 佔位。

  【最容易錯的地方】z 的數量必須和 t 的字數完全一樣。
  上面的例子 t 有 9 個字（含句號），z 也是 9 個（最後一個是 -）。
  數量對不上，那一題會被跳過，並在瀏覽器主控台留下警告。

── 注音怎麼查 ──────────────────────────────────────────────────

  教師控制台 → 注音校對台，會列出全部題庫的每一個字與注音，
  破音字自動標紅框，也可以匯出 Excel 離線核對。
  那個畫面是唯讀的，改還是要回來改這裡的 JSON。

── 編碼 ────────────────────────────────────────────────────────

  存檔請選 UTF-8。用記事本另存新檔時，編碼那一欄要選 UTF-8。

── 如果改壞了 ──────────────────────────────────────────────────

  game.html 內建一份完整題庫當後備。
  JSON 格式錯誤、檔案刪掉、或直接用 file:// 開啟網頁時，
  遊戲會自動用內建的那份，不會壞掉。
  想全部復原，把 banks 資料夾刪掉即可。
